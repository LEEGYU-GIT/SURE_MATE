- 기간: 2026-11-08 · 브랜치: `m1-shell` · 계획: `docs/superpowers/plans/2026-11-07-m1-palette-shell.md`
- 검증 환경: Windows 11 Home(개발 PC), 모니터 1대(125%), Node 24.13.1, Electron 45.2.3

## 검증하며 찾아 고친 것

1. **Claude 데스크톱 앱이 Ctrl+Alt+Space를 쓰고 있음.** 기본 팔레트 단축키가 등록되지 않았다. 다른 앱이 잡고 있으면 다음 후보(`` Alt+` ``)로 등록하고 설정에 저장하도록 바꿨다(트레이 알림으로 안내). 동료들도 Claude·ChatGPT 앱을 쓸 가능성이 높아 첫 실행 단축키 선택 화면(M6)이 중요하다.
2. **BOM이 붙은 settings.json을 깨진 파일로 처리.** 메모장·PowerShell로 고친 설정이 날아갈 수 있었다. BOM을 떼고 읽도록 고쳤다.
3. **검색 결과와 선택 항목이 어긋남.** 목록을 지연 렌더링하는 동안 cmdk가 사라질 항목을 선택해, Enter가 무시되거나 이전 항목이 실행됐다. 선택을 직접 관리하고, 목록이 뒤처진 상태의 Enter는 현재 검색어의 맨 위 항목을 실행하게 했다.
4. **PowerShell이 띄운 GUI 창을 터미널로 오판.** 실행 파일 이름 대신 창 클래스(콘솔·Windows Terminal)로 판단하게 했다. PowerShell로 만든 사내 도구에서도 가져오기가 된다.

시험 도구 쪽 문제(앱은 정상): 스캔 코드 없이 보낸 키는 `KeyboardEvent.code`가 비고, Alt 단독 입력은 시험 창을 메뉴 모드에 빠뜨리며, 숨김으로 실행한 시험 창은 보이지 않는 창이 된다. 모두 시험 스크립트에서 고쳤다.

## 최종 코드 검토 반영

새 검토자가 브랜치 전체를 읽고 "고친 뒤 병합"으로 판정했다(치명 0, 중요 8, 사소 12). 자동 시험이 키를 즉시 떼고 자동 반복 지연(약 0.5초)도 흉내 내지 않아, 사람 손 타이밍에서 생기는 문제를 놓쳤다. 중요 8건과 등급을 올린 1건을 모두 고쳤다. 건마다 실패하는 테스트를 먼저 쓰고 실제 앱에서 사람 손 타이밍으로 다시 확인했다.

1. 단축키를 누르고 있으면 약 0.5초 뒤 첫 자동 반복이 팔레트를 닫았다 → 키를 뗄 때까지 다시 받지 않는다(최대 3초).
2. 보조키를 누른 채 Ctrl+Insert·Ctrl+C·Ctrl+V를 보낼 수 있었다(워드에서 Ctrl+Alt+C는 ©) → 0.5초 넘게 누르고 있으면 보내지 않는다.
3. 보조키를 늦게 떼면 Ctrl+C 대기 시간이 거의 0이 됐다 → 단계마다 따로 재고, 시간을 넘겨 끝난 복사는 0.5초 더 지켜보다 되돌린다.
4. 가져오기가 겹쳐 원래 클립보드를 잃을 수 있었다 → 가져오기·붙여넣기는 한 번에 하나만.
5. 탐색기 파일 복사처럼 웹 형식이 없는 클립보드를 빈 것으로 보고 지웠다 → Win32로 형식 수를 센다.
6. 설정 파일 읽기·옮기기 실패가 앱 시작을 멈췄다 → 기본값으로 계속, IPC를 먼저 연다.
7. 트레이 툴팁이 대체된 단축키를 몰랐다 → 등록 뒤 다시 그린다.
8. UAC가 꺼진 PC에서 모든 창을 관리자 권한 창으로 막았다 → Sure-Mate도 관리자 권한이면 막지 않는다.
9. (등급 올림) 회사 보안 프로그램이 서명 없는 `koffi.node`를 막으면 앱이 창·트레이 없이 죽었다 → 처음 쓸 때 불러오고, 실패해도 팔레트는 뜬다.

사소 12건은 미뤘다(목록은 작업 폴더 기록과 최종 보고에 있다). 남은 설계 질문 하나: 가져오기 중 대상 앱이 복사한 선택 글은 원래 클립보드를 되돌려도 Win+V 기록·클라우드 동기화에 남을 수 있다.

## 아직 확인하지 못한 것 (사람 손이 필요)

`docs/reports/company-pc-checklist.md`에 순서대로 정리했다.

- 한글 IME(새/이전 버전)에서 음절 중간 Enter의 실제 이벤트 순서 → Enter 처리 방식 확정
- 배율이 다른 모니터 사이 창 옮기기(노트북 150% ↔ 외부 100%)
- Word·HWP·Chrome·Excel·사내 웹에서 선택 텍스트 가져오기와 클립보드 복원
- Win+V 기록에서 빠지는지
- 회사 PC의 SmartScreen·백신 반응, 단축키 충돌, 게시판 첨부 용량

## M2 이후 순서 (초안)

1. **M2 템플릿·프롬프트 (11/9~10):** 템플릿 엔진(자리표시자), 기본 프롬프트 팩 8종 초안, 확인 화면, AI 대상 열기
2. **M3 가명 처리 (11/10~11):** 모드(끔/되돌리기/빼기), 분류별 켜기·끄기, 미리 보기, 되돌리기와 조사 보정
3. **M4 용어 사전·사이드 패널·상용구 (11/11~12):** 랭커(초성·자모·오입력), 기본 용어 팩, 가져오기/내보내기, `{{terms}}`, 사이드 패널
4. **M5 워크스페이스 (11/13):** 배치 저장·복원, 모니터 구성별 저장
5. **M6 마무리 (11/14~15):** 말하듯 입력, 설정 화면, 온보딩(단축키 선택), 파일 가명 처리(Should)

11/9 회사 PC 점검 결과를 보고 M2 계획을 확정한다.
