# 회사 PC 점검표 (11/9 월요일)

시험용 설치 파일: `desktop/dist/Sure-Mate-Setup-0.1.0.exe` (113,509,785바이트, 약 108MB, 최종 검토 수정 반영본)
SHA-256: `3ED4CA528DA1A522CC2027EBA49FC8F9180AA20976218402399829AD88973708`

집에서 회사 PC로 옮길 때 파일이 바뀌지 않았는지 PowerShell에서 확인: `Get-FileHash .\Sure-Mate-Setup-0.1.0.exe`

로그 위치: `%APPDATA%\Sure-Mate\logs\<날짜>.log` (선택한 글 내용은 남지 않고 글자 수만 남는다)

## 1. 설치

- [ ] 설치 파일 실행 → SmartScreen("Windows의 PC 보호")이 뜨는지, 뜨면 "추가 정보 → 실행"으로 진행되는지 (화면 캡처)
- [ ] 백신·보안 프로그램 반응(차단, 격리, 경고) 기록 (프로그램 이름과 메시지)
- [ ] 관리자 권한 창 없이 설치되는지
- [ ] 설치 후 트레이(작업 표시줄 오른쪽 아래)에 아이콘이 생기는지
- [ ] 트레이에 "보안 프로그램이 Win32 기능을 막아…" 알림이 뜨는지. 뜨면 보안 프로그램이 `koffi.node`를 막은 것이다. 팔레트는 그래도 열려야 한다. 로그의 `native.unavailable` 줄을 기록

## 2. 단축키

- [ ] 트레이 아이콘에 마우스를 올려 표시되는 팔레트 단축키 확인(실제로 잡힌 조합이 보인다). 집 PC에서는 Claude 앱이 Ctrl+Alt+Space를 써서 `` Alt+` ``로 바뀌었다. 회사 PC에서 어떤 조합이 잡히는지 기록
- [ ] 그 단축키로 팔레트가 뜨는지, Esc로 닫으면 원래 쓰던 창으로 돌아가는지
- [ ] 팔레트 단축키를 **1.5초 동안 누르고 있기** → 팔레트가 열린 채로 있는지(열렸다 바로 닫히면 기록)
- [ ] 팔레트 단축키를 빠르게 두 번 → 한 번만 반응하는지
- [ ] 회사에서 쓰는 도구(메신저, ChatGPT·Copilot·Claude 앱, PowerToys 등)의 전역 단축키와 겹치는지

## 3. 한글 입력 (팔레트 → `ime` 입력 → "개발: 한글 입력 기록기")

- [ ] 기록기 입력칸에 "가나다"를 치다가 "다"를 조합하는 중에 Enter를 누름 → 다시 쳐서 ↓, Esc, Tab, Space도 각각 한 번씩
- [ ] 오른쪽 이름 칸에 "새 IME"로 두고 [JSON 저장]
- [ ] Windows 설정 → 시간 및 언어 → 언어 및 지역 → 한국어 → 키보드 → Microsoft 입력기 → "이전 버전의 Microsoft IME 사용"을 켠 뒤, 같은 순서로 다시 기록하고 이름 "이전 IME"로 저장 (끝나면 원래대로 끄기)
- [ ] 팔레트 검색창에 "회의록"을 치고 바로 Enter → "회의록 정리"가 한 번만 실행되는지(팔레트가 닫힘)

## 4. 창 옮기기·배율 (팔레트 → `window` / `monitor`)

- [ ] "개발: 창 목록"에 메모장·Word·Excel·브라우저가 보이는지, 모니터 수와 배율이 맞는지
- [ ] 노트북(배율 150% 등) + 외부 모니터(100%)를 연결한 상태에서, 메모장을 누른 뒤 팔레트 → "개발: 직전 창을 다른 모니터 왼쪽 절반으로" → 결과의 "차이"가 10px 이하인지. 반대 방향(외부 → 노트북)도
- [ ] Word·Excel도 같은 방법으로 (최대화한 상태에서도)
- [ ] 마우스를 각 모니터에 두고 팔레트를 열어 크기가 비슷해 보이는지. 로그의 `palette.show` 줄에서 모니터별 `bounds`의 width·height 기록(목표 720×460 근처)

## 5. 선택 텍스트 가져오기 (`Ctrl+Alt+W` → 위키 카드)

`Ctrl+Alt+W`는 선택한 글을 가져와 위키 카드를 띄운다. 가져오기 결과 수치(방법·걸린 시간·클립보드 복원)는 로그 `wiki.card` 줄에서 확인한다.
먼저 아무 글이나 복사해 두고(원래 클립보드), 각 앱에서 글을 선택한 뒤 `Ctrl+Alt+W`:

| 앱 | 카드가 뜨나(`kind`) | 방법(`method`: ctrl-insert / ctrl-c) | 걸린 시간(`elapsedMs`) | 원래 클립보드 돌아오나(`restored`) |
|---|---|---|---|---|
| 메모장 | | | | |
| Word | | | | |
| 한글(HWP) | | | | |
| Chrome·Edge | | | | |
| Excel 셀 | | | | |
| 사내 웹 그룹웨어 | | | | |

- [ ] 아무것도 선택하지 않고 `Ctrl+Alt+W` → 1초 안팎(가져오기의 늦은 복사 확인이 끝난 뒤, 최대 약 0.5초 더) 뒤에 "선택한 글이 없어요" 안내 카드가 뜨고 클립보드가 그대로인지
- [ ] `Ctrl+Alt+W`를 **1초 누르고 있기**, **빠르게 두 번** → 카드가 한 번만 뜨고(두 번째 `wiki.card` 줄은 `kind`가 null) 원래 클립보드가 돌아오는지
- [ ] Word에서 글을 선택하고 `Ctrl+Alt+W`를 누른 뒤 **Ctrl·Alt를 1초쯤 늦게 떼기** → "단축키를 누른 채라 가져오지 않았어요" 안내 카드가 뜨고 선택한 글이 바뀌지 않는지(©가 입력되지 않는지)
- [ ] 탐색기에서 파일을 복사(Ctrl+C)한 뒤 메모장 글을 선택하고 `Ctrl+Alt+W` → 로그 `wiki.card`의 `restored`가 false로 기록되는지. 탐색기에서 붙여넣으면 파일 대신 글이 붙는다(파일 복사는 되돌리지 못하는 한계, 집 PC에서 확인함)
- [ ] 큰 이미지(화면 캡처 등)를 복사해 둔 상태에서 가져오기 시간이 크게 늘어나는지
- [ ] 명령 프롬프트·PowerShell 창에서 `Ctrl+Alt+W` → "터미널에서는 가져오지 않아요" 안내 카드가 뜨는지
- [ ] Win+V 클립보드 기록이 켜져 있는지, 가져오기 뒤 선택한 글이 기록 목록에 남는지(대상 앱이 복사한 것이라 남을 수 있다. 결과는 설계 v4에 반영)

## 6. 붙여넣기·관리자 권한 창·클립보드 기록

- [ ] 메모장을 누른 뒤 팔레트 → `paste` → "개발: 붙여넣기 시험" → 메모장에 한 줄이 한 번만 들어가는지
- [ ] 관리자 권한으로 연 메모장(시작 → 메모장 우클릭 → 관리자 권한으로 실행)에서: `Ctrl+Alt+W` → "관리자 권한 창" 안내, 붙여넣기 시험 → "복사만 했어요", 팔레트를 Esc로 닫으면 그 메모장으로 돌아가는지
- [ ] 팔레트 → `clipboard` → "개발: 클립보드 기록 제외 시험" → Win+V를 눌러 그 글이 기록 목록에 없는지(Ctrl+V로는 붙여넣어지는지)

## 7. 바·펼침 창·위키 카드 (화면 오른쪽 가장자리의 Sure-Mate 바)

- [ ] 바가 주 모니터 오른쪽 가장자리에 세로로 뜨는지, 바 위쪽 항목(로고)에 마우스를 올리면 0.4초 뒤 이름표가 나오는지
- [ ] 메모장·Word·한글(HWP)에서 글을 선택한 채 바의 고정 프롬프트를 눌러도 선택이 그대로 남는지, 프롬프트가 복사되었다는 알림이 뜨는지(바를 눌러도 앞 창이 바뀌지 않아야 한다)
- [ ] 아무것도 선택하지 않고 고정 프롬프트를 누르면 팔레트 확인 화면이 열리는지
- [ ] 가명 처리 방패를 눌러 메뉴가 뜨고, "끔"을 선택하면 방패가 끊기고 주황 점과 "끔" 글자가 보이는지(색만으로 구분하지 않는지)
- [ ] 글을 선택하고 `Ctrl+Alt+W` → 위키 카드가 바 옆에 뜨고 약 8초 뒤 사라지는지, 카드 위에 마우스를 두면 유지되는지, [고정]을 누르면 계속 남는지
- [ ] PowerPoint 슬라이드쇼와 전체 화면 영상(브라우저 F11 포함)에서 바가 1초 안에 숨고, 끝내면 다시 나타나는지
- [ ] 작업 표시줄의 빈 곳을 누른 뒤 2초 안에 바가 다시 작업 표시줄 위로 올라오는지
- [ ] 바 빈 곳을 오른쪽 클릭 → 바 메뉴에서 "떠 있는 캡슐", "30분 동안 숨기기", "바 끄기"가 동작하고, 숨기거나 끈 뒤 트레이 "Sure-Mate 바" 또는 팔레트 "바 모양 바꾸기"로 다시 켜지는지
- [ ] 바를 위아래로 끌어 옮긴 뒤 앱을 다시 시작해도 그 위치가 유지되는지
- [ ] 모니터를 연결하거나 해제한 뒤 바가 보이는 모니터의 화면 안에 있는지(화면 밖에 남지 않는지)
- [ ] 자동 숨김을 켜고(`settings.json`의 `bar.autoHide`: true) 마우스를 바에서 떼면 1초쯤 뒤 화면 끝의 얇은 손잡이만 남고, 손잡이에 마우스를 올리면 바가 나오는지
- [ ] 배율이 다른 모니터(150% 노트북 + 100% 외부)로 바를 옮겨도 크기가 어긋나지 않는지(로그 `bar.place.mismatch`가 없는지)
- [ ] 작업 관리자에서 Sure-Mate의 메모리 합(목표 350MB 이하)과 바만 떠 있을 때 5분 평균 CPU(목표 1% 미만) 기록

## 8. 기타

- [ ] UAC 설정 기록: PowerShell에서 `(Get-ItemProperty HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System).EnableLUA` → 1이면 켜짐, 0이면 꺼짐(꺼진 PC에서도 관리자 권한 창 판단이 맞는지 보려는 것)
- [ ] 게시판 첨부 파일 용량 제한 (설치 파일 약 108MB가 올라가는지)
- [ ] 회사에서 허용된 AI와 그 주소(Claude, ChatGPT, Gemini, 사내 LLM 등)
- [ ] 다 끝나면: 트레이 아이콘 우클릭 → 종료, 설정 → 앱 → Sure-Mate 제거 (원하면 계속 써도 됨)

결과는 이 파일에 적거나 사진으로 남겨 주시면 M2 계획에 반영한다.
