## 5. 선택 텍스트 가져오기 (`Ctrl+Alt+W` → 위키 카드)

`Ctrl+Alt+W`는 선택한 글을 가져와 위키 카드를 띄운다. 가져오기 결과 수치(방법·걸린 시간·클립보드 복원)는 로그 `wiki.card` 줄에서 확인한다.
먼저 아무 글이나 복사해 두고(원래 클립보드), 각 앱에서 글을 선택한 뒤 `Ctrl+Alt+W`:

| 앱 | 카드가 뜨나(`kind`) | 방법(`method`: ctrl-insert / ctrl-c) | 걸린 시간(`elapsedMs`) | 원래 클립보드 돌아오나(`restored`) |
|---|---|---|---|---|
| 메모장 | | | | |
| Word | | | | |
| 한글(HWP) | | | | |
| Chrome·Edge | | | | |
| Excel 셀 | | | | |
| 사내 웹 그룹웨어 | | | | |

- [ ] 아무것도 선택하지 않고 `Ctrl+Alt+W` → 1초 안팎(가져오기의 늦은 복사 확인이 끝난 뒤, 최대 약 0.5초 더) 뒤에 "선택한 글이 없어요" 안내 카드가 뜨고 클립보드가 그대로인지
- [ ] `Ctrl+Alt+W`를 **1초 누르고 있기**, **빠르게 두 번** → 카드가 한 번만 뜨고(두 번째 `wiki.card` 줄은 `kind`가 null) 원래 클립보드가 돌아오는지
- [ ] Word에서 글을 선택하고 `Ctrl+Alt+W`를 누른 뒤 **Ctrl·Alt를 1초쯤 늦게 떼기** → "단축키를 누른 채라 가져오지 않았어요" 안내 카드가 뜨고 선택한 글이 바뀌지 않는지(©가 입력되지 않는지)
- [ ] 탐색기에서 파일을 복사(Ctrl+C)한 뒤 메모장 글을 선택하고 `Ctrl+Alt+W` → 로그 `wiki.card`의 `restored`가 false로 기록되는지. 탐색기에서 붙여넣으면 파일 대신 글이 붙는다(파일 복사는 되돌리지 못하는 한계, 집 PC에서 확인함)
- [ ] 큰 이미지(화면 캡처 등)를 복사해 둔 상태에서 가져오기 시간이 크게 늘어나는지
- [ ] 명령 프롬프트·PowerShell 창에서 `Ctrl+Alt+W` → "터미널에서는 가져오지 않아요" 안내 카드가 뜨는지
- [ ] Win+V 클립보드 기록이 켜져 있는지, 가져오기 뒤 선택한 글이 기록 목록에 남는지(대상 앱이 복사한 것이라 남을 수 있다. 결과는 설계 v4에 반영)

- [ ] 조종 중과 조종 뒤에 작업 표시줄에 펫 단추가 생기지 않는지
- [ ] 조종 중 설정 창이나 팔레트를 클릭하면 포커스가 그 창에 남고(펫이 다시 가져가지 않고) 조종이 끝나는지
- [ ] Win32 기능이 막힌 PC(1번의 "보안 프로그램이 Win32 기능을 막아…" 알림이 뜬 PC)에서 조종 중 Esc를 눌렀을 때 포커스가 어디로 가는지 기록(원래 창으로 돌아오지 못하는 것이 예상 동작이며, 펫은 그대로 표시·이동해야 한다). 개발 PC에서는 `t12-run-blocked.ps1`처럼 koffi.node를 숨긴 뒤 같은 동작으로 재현할 수 있다
- [ ] 펫 메뉴의 "펫 설정"이 설정 창을 말랑 메이트 탭으로 여는지: 설정 창이 닫혀 있을 때, 다른 탭(예: 일반)이 열려 있을 때, 첫 실행 안내(온보딩) 화면이 떠 있을 때(온보딩 중에는 어떻게 동작하는지 기록)
- [ ] 설정 → 말랑 메이트 탭에서 조종 단축키를 지정하면 앱을 다시 시작하지 않고 바로 동작하고, 지우면("없음") 바로 해제되는지. 다른 단축키(팔레트·조회)와 겹치는 조합이나 다른 프로그램이 사용하는 조합을 선택하면 이전 단축키가 그대로 유지되고 안내가 뜨는지
- [ ] 조종 단축키를 입력하는 동안(기록 중) 기존 조종 단축키가 동작하지 않는지(입력이 끝나거나 취소하면 다시 동작)
- [ ] 펫을 숨긴 상태에서 조종 단축키를 누르면 "숨어 있어요" 안내가 누를 때마다 한 번만 뜨고 조종은 시작하지 않는지
- [ ] Windows 설정 → 접근성 → 시각 효과의 "애니메이션 효과"를 끄면 펫이 부풀기·튀기·흔들림 없이 자리만 옮기는지(설정의 움직임 줄이기를 켠 것과 같은 모양). 다시 켠 뒤 펫을 한 번 숨겼다 보이면 원래대로 돌아오는지
- [ ] 바의 자동 숨김이 켜진 상태에서 바 꼭대기에 앉은 펫이 바가 접힐 때 떨어지고, 바가 다시 펴지면 다시 올라오는지(자주 떨어지면 기록)
- [ ] 배율이 다른 두 모니터에서 펫이 바가 있는 모니터 밖으로 나가지 않고, 화면 가장자리에서 크기가 어긋나지 않는지
- [ ] 화면 읽기 프로그램(내레이터)이 펫 말풍선("프롬프트를 복사했어요…")을 읽어 주는지(펫 창은 포커스를 받지 않으므로 확인 필요, 읽지 않으면 기록)
- [ ] 작업 관리자에서 Sure-Mate 프로세스 합의 메모리(목표 350MB 이하)와, 입력하지 않고 5분 동안 펫이 혼자 놀다 졸 때의 평균 CPU(목표 1% 미만). 개발 PC에서는 `t20-run.ps1 -Idle`로 같은 값을 잰다

## 9. 워크스페이스 (창 배치 저장·불러오기)

개발 PC에서는 자동 시험 t22(`desktop/scripts/smoke`, `t22-run.ps1`)가 팔레트의 `@이름` 저장과 문장으로 불러오기를 확인한다. 아래는 회사 PC의 실제 업무 앱에서 사람이 확인할 항목이다.

저장은 팔레트에 `@`와 이름(예: `@회의 배치`)을 입력한 뒤 목록 끝 "‘회의 배치’ 이름으로 지금 배치 저장" 줄에서 Enter를 누르고, 불러오기는 `@`와 이름을 입력한 뒤 그 워크스페이스 행에서 Enter를 누른다.

- [ ] Excel 창 2개(통합 문서 두 개), 한글(HWP) 창 2개, Outlook 창 2개(받은 편지함과 열어 둔 메일 한 통)를 서로 다른 위치·크기로 배치한 뒤 저장 → 알림의 창 수에 6개가 모두 포함되는지(최소화한 창이 있으면 "최소화된 창 N개는 빼고 저장" 문구가 함께 표시되는지)
- [ ] 6개 창을 옮기거나 크기를 바꾸고 일부는 최소화·최대화한 뒤 불러오기 → 저장한 위치·크기로 돌아오는지, 같은 프로그램의 두 창이 서로 자리를 바꾸지 않는지, 불러온 뒤 불러오기 전에 사용하던 창이 앞에 있는지. 알림 문구("창 6개 모두 배치했어요" 또는 "창 6개 중 N개 배치 · … 못 찾음" 등) 기록
- [ ] 한글(HWP)·Outlook에서 다른 문서·메일을 열어 창 제목이 바뀐 상태에서 불러오기 → 어느 창이 어디로 옮겨지는지 기록(저장한 제목 규칙과 맞지 않는 창은 "못 찾음"으로 표시된다)
- [ ] 노트북을 도킹 해제(외부 모니터 분리)한 뒤 불러오기 → "다른 모니터 구성에서 저장한 배치예요. 주 모니터로 모을까요?" 질문 창이 표시되는지, "주 모니터로 모으기"를 선택하면 모든 창이 노트북 화면 안에 모이는지(제목 줄이 화면 밖으로 나가지 않는지), "취소"를 선택하면 아무 창도 옮겨지지 않는지. 다시 도킹하면 질문 없이 저장한 모니터로 돌아가는지
- [ ] 저장·불러오기 때 보안 프로그램 경고(창 제어·키 입력 감시 등)가 표시되는지(프로그램 이름과 메시지 기록). Win32 기능이 막힌 PC(1번의 "보안 프로그램이 Win32 기능을 막아…" 알림이 표시된 PC)에서는 저장·불러오기를 실행하면 "보안 프로그램이 Win32 기능을 막아 창을 옮기거나 저장할 수 없어요." 알림만 표시되고 창이 옮겨지지 않는지

아래는 설정 창의 워크스페이스 탭(트레이 "설정" → 워크스페이스)과 연결된 항목이다. 개발 PC에서는 자동 시험 t21(`t21-run.ps1`)이 저장 뒤 열리는 탭의 이름 변경, 단축키 녹화, 바 워크스페이스 메뉴를 확인한다.

- [ ] 팔레트에 `@`만 입력하고 맨 위 "지금 배치 저장"에서 Enter → 설정 창 워크스페이스 탭에 새 워크스페이스("배치 N")가 열리고 이름 칸 전체가 선택되는지. 한글 자판으로 이름(예: 회의 배치)을 입력하고 마지막 글자를 조합하는 중에 Enter → 이름이 한 번만 저장되고(글자 빠짐·겹침 없음) 팔레트 `@회의`로 그 워크스페이스가 검색되는지
- [ ] 탭에서 Excel 창 하나의 포함 체크를 해제하고 불러오기 → 그 창은 옮겨지지 않는지. 다른 Excel 창의 '제목에 포함' 칸에 통합 문서 이름 일부를 입력하고(칸을 벗어나면 저장) 불러오기 → 그 통합 문서 창만 그 자리로 옮겨지는지
- [ ] 단축키 "정하기"로 조합(예: Ctrl+Alt+1)을 녹화한 뒤 Excel·한글(HWP)·Outlook이 앞에 있을 때 누르기 → 불러오기가 실행되는지. 사내 메신저·보안 프로그램이 같은 조합을 사용하면 녹화 칸에 "다른 앱이 이 조합을 쓰고 있어요"가 표시되는지, 앱을 시작할 때 다른 프로그램이 먼저 등록한 조합은 탭에 "등록 못 함"으로 표시되는지
- [ ] 바의 워크스페이스 단추 → "모두 보기·편집" → 설정 창 워크스페이스 탭(목록)이 열리는지. 팔레트에서 `@`와 이름을 입력하고 워크스페이스 행에서 Ctrl+Enter(또는 →) → 설정 창에서 그 워크스페이스가 열리는지

## 10. 말하듯 입력 (팔레트에 문장으로 입력)

개발 PC의 t22는 문장을 KEYEVENTF_UNICODE로 입력하므로 한글 IME 조합을 거치지 않는다. 아래는 실제 한글 자판으로 입력해 확인한다. Microsoft IME 새 버전과 이전 버전에서 각각 확인한다(이전 버전은 3번과 같은 설정 "이전 버전의 Microsoft IME 사용", 끝나면 원래대로 끄기).

| 입력 | 맨 위에 와야 하는 항목 | 의도 표시 | 새 IME | 이전 IME |
|---|---|---|---|---|
| 회의록 정리해줘 | 회의록 정리 | 프롬프트 | | |
| 가명 되돌려줘 | 가명 되돌리기 | 가명 처리 | | |
| mcdc 뭐야 | MC/DC | 용어 뜻 | | |
| 혹시 커버리지 뜻 좀 알려주세요 | 코드 커버리지 | 용어 뜻 | | |

- [ ] 위 문장의 마지막 글자를 조합하는 중에 Enter → 맨 위 항목이 한 번만 실행되는지(두 번 실행되거나 Enter를 한 번 더 눌러야 하면 기록)
- [ ] 영문 자판 상태로 "회의록 정리해줘"를 입력(입력줄에 `ghldmlfhr wjdflgownj` 표시) → 맨 위가 "회의록 정리"인지
- [ ] 맨 위가 원하는 항목이 아닌 문장(예: "보고서 띄워줘")에서 ↓로 원하는 행을 선택 → 행 오른쪽에 "Shift Enter 기억하고 실행" 안내가 표시되는지. Shift+Enter 뒤 같은 문장을 다시 입력하면 그 항목이 맨 위에 "기억한 문장" 표시와 함께 오는지. 마지막 글자를 조합하는 중에 Shift+Enter를 눌렀을 때도 확인

## 11. 기타

- [ ] UAC 설정 기록: PowerShell에서 `(Get-ItemProperty HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System).EnableLUA` → 1이면 켜짐, 0이면 꺼짐(꺼진 PC에서도 관리자 권한 창 판단이 맞는지 보려는 것)
- [ ] 게시판 첨부 파일 용량 제한 (설치 파일 약 108MB가 올라가는지)
- [ ] 회사에서 허용된 AI와 그 주소(Claude, ChatGPT, Gemini, 사내 LLM 등)
- [ ] 다 끝나면: 트레이 아이콘 우클릭 → 종료, 설정 → 앱 → Sure-Mate 제거 (원하면 계속 써도 됨)
