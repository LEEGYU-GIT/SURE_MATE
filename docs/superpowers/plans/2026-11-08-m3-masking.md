# M3 가명 처리 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AI로 보내는 프롬프트에서 고객사·프로젝트·인물·시스템 이름과 IP·경로·이메일·전화번호·사내 URL을 찾아 모드(끔/가명 후 되돌리기/결과에서 빼기)대로 가리고, AI 답을 원래 이름과 맞는 조사로 되돌린다. 확인 화면에서 모드와 항목을 이번 실행만 바꿀 수 있다.

**Architecture:** 찾기(사전·패턴)·겹침 정리·가리기·되돌리기·조사 고르기는 `src/shared/masking/`의 순수 함수다. 대응표는 main 메모리에만 두는 `MappingTable`(8시간)이고, 미리 보기는 표를 복제해 써서 토큰을 확정하지 않는다. 프롬프트 세션(M2)의 미리 보기·실행이 마지막 단계로 가리기를 부른다.

**Tech Stack:** TypeScript, Vitest (새 패키지 없음)

**Spec:** `docs/superpowers/specs/2026-11-05-sure-mate-design.md` §8 F2 (+ §5 로컬 파일, §6 상태 표시줄, §7 확인 화면, §14 설정)

## Global Constraints

- 가명 대응표·사전·찾은 이름은 로그에 남기지 않는다(건수·분류만). 대응표는 디스크에 쓰지 않는다.
- 사전 파일 `%APPDATA%\Sure-Mate\masking-dictionary.json`은 로컬 전용. 형식 `{ format: 'sure-mate-masking', version: 1, terms: MaskTerm[] }`.
- 정규화는 NFC + 전각(U+FF01~FF5E, U+3000) 접기 + 소문자. NFKC 금지.
- 되돌린 글을 클립보드에 쓸 때는 `writeExcludedFromHistory`(Win+V 기록 제외)를 쓴다.
- 모드 우선순위: 실행할 때 고른 값 > 템플릿 기본값(`default`가 아니면) > 전체 기본값.
- 끔일 때 확인 화면에 주황 띠 "가명 처리 꺼짐 — 원문 그대로 복사됩니다".
- 데모·테스트 데이터의 회사 이름은 가상(가상자동차, XY방산 등)만 쓴다.
- M2의 Global Constraints(버전 고정, 네트워크 없음, 익명, TDD, PowerShell, §14-4 토큰)를 그대로 따른다.

## Review Focus

1. **조사 붙은 이름과 영문 경계**: "가상자동차에서"는 찾고 "주가상자동차"(한글 구간 중간)는 안 찾음, 'GP'는 'GPL'에 안 걸림, 'XY방산는'은 찾음. → Task 3 테스트.
2. **AI가 바꿔 쓴 토큰**: `Client_A`, `CLIENT A`, `[CLIENT_A]`, `client-a`를 되돌리고, 대응표에 없는 `CLIENT_C`와 남은 토큰은 경고. → Task 5 테스트.
3. **원문에 이미 있는 토큰 모양**: 원문에 "CLIENT_A"라는 글자가 있으면 새 토큰은 CLIENT_B부터. → Task 4 테스트.
4. **미리 보기 반복**: 확인 화면에서 미리 보기를 여러 번 불러도 대응표가 늘지 않고, 실행한 뒤에만 토큰이 확정된다. 같은 이름은 다음 프롬프트에서도 같은 토큰. → Task 4·7 테스트.
5. **끄기의 범위**: 분류 하나(IP)를 끄면 그 분류만 원문, 항목 하나를 끄면 그 이름(같은 키의 모든 자리)만 원문. 템플릿 기본값이 끔이면 전체 기본값이 되돌리기여도 끔으로 시작. → Task 4·7 테스트.
