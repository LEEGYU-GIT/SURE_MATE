## 0. 이 문서를 받은 Claude Code에게

이 문서는 사용자와 대화로 확정한 설계다. 아이디어 논의는 끝났으니 다시 브레인스토밍하지 말고, 이 문서로 구현 계획을 세운 뒤 §18 "첫 작업"부터 진행한다.

- 문서와 다르게 가는 게 낫다고 판단되면, 바꾸기 전에 이유를 들어 먼저 묻는다.
- 문서에 없는 결정은 합리적으로 정하고 `docs/decisions.md`에 한 줄씩 남긴다. 잘못 정하면 일정이 크게 흔들리는 결정만 묻는다.
- 단계가 끝날 때마다 ① 앱을 실제로 실행해 확인하고 ② 테스트 결과를 보여 주고 ③ 남은 위험을 보고한 뒤 멈춘다.
- 의존성은 최소한으로 둔다. 새 패키지를 넣기 전에 이름과 이유를 보고한다.
- 셸은 PowerShell이다(`&&` 대신 `;` 또는 `if ($?)`).

**기억에 의존하면 틀리기 쉬운 최신 변화 (첫 작업에서 `SURE/CLAUDE.md`에 옮겨 적는다)**
- Electron 44부터 clipboard가 W3C 방식으로 바뀌었다. renderer에서 못 쓰고(main 전용), `read`/`write`/`readText`/`writeText`가 Promise를 돌려주며, `write()`는 `ClipboardItem[]`를 받는다. `readHTML`·`readRTF`·`readImage`·`availableFormats`·`readBuffer`·`writeBuffer`는 없어졌다. OS 고유 형식은 `'electron application/osclipboard;format="<이름>"'`로 다룬다. Electron 44부터 Windows 32비트(ia32) 빌드도 없다.
- koffi 3.x는 네이티브 바이너리가 플랫폼별 선택 패키지(`@koromix/koffi-win32-x64`)로 나뉘었고 포인터가 BigInt다. `JSON.stringify`가 BigInt에서 실패하므로 HWND는 IPC·저장 전에 문자열로 바꾼다.
- Electron 맞춤법 검사기는 기본으로 켜져 있고 사전을 Google CDN에서 내려받는다. 모든 창에서 끈다.
- Electron `globalShortcut`은 Windows에서 RegisterHotKey를 쓰고, 이미 다른 앱이 잡은 조합이면 `register()`가 false를 돌려줄 뿐 오류를 내지 않는다. 누르고 있으면 콜백이 반복된다.

## 1. 배경과 목표

**회사.** 슈어소프트테크는 소프트웨어 시험·검증 회사다. 직원 PC는 관리자 권한이 없거나 사내 프록시 뒤에 있을 수 있고, 고객사 자료(국방·자동차 등)를 다룬다.

**공모전: 2026 슬기로운 AI 생활 (사내 AI 활용 사례 공유 프로그램)**
- 접수 2026-10-28 ~ 11-18, 그룹웨어 게시판에 **익명**으로 소개글 + **다른 사람이 내려받아 실행할 수 있는 자료와 사용 안내** 첨부.
- 소개글 필수 항목: 어떤 업무에 · 무엇이 좋아졌는지 · **AI를 어떻게** · 사용법.
- 심사(12월, 임원진 + 관련 실무자, **심사위원이 직접 실행**):
  - 업무 적합성: 업무 문제와 AI 활용 방법이 맞는지, **업무의 제약과 필요한 정확성을 고려한 정도**
  - 업무 개선 효과: 시간·수작업·오류 감소, 결과물 품질
  - 확산 가치: 다른 사람이 자기 업무에 쓰거나 응용할 수 있는 정도
  - 좋아요·댓글 참고
- 시상: 대상 1(300만), 우수상 3(서로 다른 부문에서 1명씩, 각 100만), 인기상 1(좋아요 최다, 100만). 한 사람이 여러 건 응모 가능.
- 부문: 회의와 업무 기록 · 문서와 발표 자료 · 자료 조사와 지식 검색 · 데이터 분석과 시각화 · 개발과 검증 · 업무 비서와 반복 작업 자동화 · 자유 주제.

**제품 한 줄.** 단축키 한 번으로 우리 회사 업무에 AI를 쓰게 해 주는 팔레트. 선택한 글을 회사 업무용 프롬프트로 조립하고, 사내 용어 설명을 붙여 정확도를 높이고, 고객사명·IP·경로를 상황에 따라 가리거나 그대로 두고, 쓰던 AI 창을 열어 준다. 창 배치 전환과 용어 사전 사이드 패널은 일상 편의 기능으로 함께 준다.

**AI를 쓰는 방식.** 앱이 AI API를 직접 부르지 않는다. 프롬프트를 조립해 클립보드에 넣고, 사용자가 회사에서 허용된 AI(Claude, ChatGPT, Gemini, Notion AI, 사내 LLM 등)에 붙여넣는다. API 키·비용·보안 승인이 필요 없고 어떤 AI든 쓸 수 있다. **앱 자체는 인터넷에 접속하지 않는다**(AI 사이트는 기본 브라우저로 연다).

**성공 기준**
- 심사위원이 설치 후 5분 안에 "글 선택 → 단축키 → 프롬프트 선택 → AI에 붙여넣기 → 가명 되돌리기"를 해 볼 수 있다.
- 기본 프롬프트 팩 8종이 실제 업무 예시(가짜 데이터)로 쓸 만한 결과를 낸다.
- 동료 업무 PC(관리자 권한 없음, 다중 모니터·배율 혼합)에서 설치·동작한다.
- 게시글의 절감 효과는 시범 사용자에게서 잰 실제 숫자다.

**실패로 보는 것**
- 가명 처리가 켜진 줄 알았는데 실명이 그대로 AI로 나가는 것(지금 상태가 늘 보여야 한다)
- 설치가 번거롭거나 PC를 느리게 해서 지우게 되는 것
- 팔레트가 굼떠서 손이 안 가는 것
- 개발 PC에서만 되고 실제 업무 PC에서 깨지는 것
- 익명 응모인데 작성자가 드러나는 것

## 5. 아키텍처

- **프로세스 역할**
  - main: 창·트레이·단축키, 네이티브 호출(koffi), 클립보드, 파일 저장, 가명 대응표(메모리)
  - preload: 타입이 정해진 IPC만 노출 (`contextBridge`)
  - renderer: UI만. `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`, `spellcheck: false`, CSP로 외부 요청 차단
- **네트워크:** 앱은 어떤 요청도 보내지 않는다. AI 사이트와 위키 링크는 `shell.openExternal`로 기본 브라우저에서 연다(http/https만).
- **창**
  - palette: 테두리 없는 창. 앱 시작 때 만들어 숨겨 두고 단축키에 바로 보여 준다(§6).
  - sidePanel: 포커스를 뺏지 않는 창(§9).
  - settings: 일반 창. 열 때 만들고 닫으면 없앤다.
  - tray: 팔레트 열기 / 가명 처리 상태(클릭으로 바꾸기) / 설정 / 단축키 일시 중지 / 종료. 툴팁에 현재 단축키와 가명 처리 모드 표시.
- **네이티브 모듈 경계:** koffi 호출은 `desktop/src/main/native/` 한곳에 모으고 타입 있는 함수(`listWindows`, `moveWindow`, `getForeground`, `setForeground`, `sendKeys`, `clipboardSeq`, `modifiersDown` 등)로 감싼다. 좌표 계산 같은 순수 로직은 따로 두고 단위 테스트한다. Electron 창·`screen` API는 DIP, koffi로 얻는 Win32 좌표는 물리 픽셀이다. 변환은 `screen.dipToScreenRect`/`screenToDipRect`로 한 곳에서만 한다.
- **로컬 파일** (`%APPDATA%\Sure-Mate\`)
  - `settings.json`(단축키, 사이드 패널, AI 대상, 가명 처리 설정 등), `workspaces.json`, `templates/*.json`(사용자 템플릿), `glossary.json`(사용자 용어·수정본), `intents.json`, `phrase-map.json`, `masking-dictionary.json`, `references/<종류>.txt`, `logs/`
  - 기본 용어 팩·프롬프트 팩·단어 목록은 `resources/`에서 읽기 전용으로 읽고, 사용자가 고치면 사용자 파일에 덮어쓰기본으로 저장한다.
  - 저장은 임시 파일에 쓰고 이름 바꾸기(원자적 저장). 파일이 깨졌으면 백업에서 복구한다.

## 6. F0 팔레트 공통 기반

- **단축키**
  - 첫 실행 때 고르게 한다. 후보: Alt+Space(비어 있을 때만), `Ctrl+Alt+Space`(기본 제안), `` Alt+` ``. 고르는 즉시 등록해 보고 "다른 앱이 사용 중"이면 바로 알린다.
  - Win 키 조합, F12, 오른쪽 Alt(한/영)·오른쪽 Ctrl(한자) 조합은 막는다. IDE 자동완성 조합(Ctrl+Space 등)은 경고한다.
  - 바꿀 때는 기존 등록 해제 → 새로 등록 → 실패하면 되돌리기. 키 녹화 중에는 모든 단축키를 잠시 해제한다. 설정을 가져온 뒤에는 다시 등록해 본다.
  - 누르고 있으면 콜백이 반복되므로 250ms 안의 반복은 무시한다.
- **팔레트 창 옵션:** `show:false, frame:false, type:'toolbar', skipTaskbar:true, backgroundThrottling:false, roundedCorners:true, backgroundMaterial:'acrylic'`(Windows 11 22H2 이상, 안 되면 CSS 단색). `transparent:true`는 쓰지 않는다.
- **열기:** 단축키 → 현재 활성 창 HWND 저장 → (선택한 글 가져오기가 필요한 동작이면 이때 가져옴, §7) → 표시할 모니터(설정: 마우스 위치/주 모니터/활성 창 모니터) 가운데에 놓고 표시 → 입력칸 포커스.
  - 표시 직후 150ms 동안은 blur를 무시한다. 관리자 권한 창 위에서는 포커스를 못 가져올 수 있다(알려진 제약).
  - 배율이 다른 모니터로 옮겨 표시할 때 Electron 창 크기가 커지는 버그(electron#27651)가 있으므로, 위치를 정한 뒤 크기를 한 번 더 맞추고 `getBounds()`로 확인한다.
- **닫기:** Esc, 바깥 클릭(blur), 실행 완료 → 입력칸 blur → 검색어·결과 초기화 → 숨김 → 저장해 둔 창으로 포커스 복귀(창이 사라졌으면 생략).
- **한글 입력 규칙 (모든 입력칸 공통)**
  - 조합 중 판단: `e.nativeEvent.isComposing || e.keyCode === 229`. 조합 중에는 Enter·화살표·Tab·Space로 동작을 실행하지 않는다. 키 비교는 `e.key` 말고 `e.code`+보조키로 한다(한글 모드에서 `e.key`는 `'Process'`).
  - 검색은 조합 중에도 입력 이벤트마다 돌린다. 입력값은 그대로 두고 정규화는 파생 검색어에만 한다. 결과 목록은 `useDeferredValue`로 그린다.
  - 같은 항목을 300ms 안에 두 번 실행하지 않는다.
- **결과 목록:** 프롬프트 / 명령 / 워크스페이스 / 상용구 / 위키 구역으로 묶고, ↑↓ 이동, Enter 실행, → 또는 Ctrl+Enter로 상세·보조 동작. 맨 위 후보에는 의도 표시(예: "프롬프트", "배치")를 붙인다.
- **접두어 (한/영 상태와 상관없이 같은 기호):** `?` 위키, `!` 상용구, `/` 프롬프트, `@` 워크스페이스, `>` 명령·설정. 접두어가 없으면 F6 말하듯 입력이 처리한다.
- **상태 표시줄 (팔레트 아래쪽 한 줄):** 가명 처리 모드(색으로 구분: 끔은 주황), 기본 AI 대상, 선택한 글 길이. 팔레트 안에서 `Alt+M`으로 가명 처리 모드를 바꾼다(끔 → 되돌리기 → 빼기).
- **빈 화면:** 최근 실행 항목, 사용 팁 한 줄.
- **기타:** 단일 실행(두 번째 실행은 팔레트 열기), 로그인 시 자동 실행(`setLoginItemSettings`, 인자 `--hidden`, 온보딩에서 선택, 기본 켬).
- **온보딩 (첫 실행 3단계):** ① 단축키 고르기 ② 주로 쓰는 AI 고르기(회사에서 허용된 것) + 가명 처리 기본 모드 고르기 ③ 예시 글로 "회의록 정리" 프롬프트를 직접 만들어 보는 30초 안내.

**완료 기준**
- 팔레트가 단축키 150ms 안에 뜨고, 닫으면 원래 창에 포커스가 돌아간다.
- 한글로 "회의록"을 치고 바로 Enter를 눌러도 글자가 빠지거나 두 번 실행되지 않는다.
- 단축키가 이미 쓰이고 있으면 고를 때 바로 알려 주고, 등록 실패를 조용히 넘기지 않는다.

## 7. F1 AI 프롬프트 팔레트 (Sure-Prompt) — 핵심 기능

**흐름**
1. 아무 앱에서 글을 선택하고 단축키(또는 팔레트 단축키 후 `/`) → 팔레트가 열리며 선택한 글을 가져온다.
2. 프롬프트를 고른다(검색·말하듯 입력 가능).
3. 확인 화면: 입력 출처(선택한 글 N자 / 클립보드 / 직접 입력), 가명 처리 칩(모드, `Alt+M`), AI 대상 칩, 감지 요약("고객사 2 · IP 1 · 경로 3", 펼치면 항목별 켜기/끄기), 최종 프롬프트 미리 보기.
4. Enter → 가명 처리된 최종 프롬프트를 클립보드에 넣고 AI 대상을 연다 → "복사됨 · 가명 7건 · Claude 열림 — Ctrl+V로 붙여넣으세요" 알림.
5. AI 답을 복사한 뒤 팔레트에서 "가명 되돌리기"(F2) → 원래 이름으로 바꿔 클립보드에 넣는다(원하면 직전 창에 바로 붙여넣기).

**템플릿**
```ts
interface Template {
  id: string
  name: string            // "회의록 정리"
  aliases: string[]       // ["회의 정리", "회의록", "미팅"]
  kind: 'prompt' | 'snippet'
  group?: string          // 회의·문서·조사·검증·자동화 등
  description?: string
  body: string            // 자리표시자 포함
  masking?: 'default' | 'off' | 'restore' | 'remove'  // prompt 전용, 이 템플릿의 기본 모드
  aiTarget?: string       // 기본 AI 대상 id
  scope: 'builtin' | 'personal' | 'imported'
}
```

**자리표시자:** `{{selection}}` 선택한 글 · `{{clipboard}}` · `{{date}}` · `{{time}}` · `{{terms}}` 입력 글에 나온 위키 용어만 "용어: 설명" 목록으로 · `{{reference:회의록}}` 해당 종류의 기준 예시 문서(`references/회의록.txt`) · (Should) `{{input:결함 위치}}` 실행 전에 팔레트에서 값 입력받기. 한 번에 채우고, 들어간 글 안의 `{{…}}`는 다시 채우지 않는다. 모르는 자리표시자는 그대로 두고 경고한다. `{{terms}}`에 해당 용어가 없으면 그 줄을 통째로 뺀다.

**용어 자동 첨부 (`{{terms}}`):** 입력 글에서 위키 용어·별칭을 가장 긴 것부터 겹치지 않게 찾는다. 영문 약어는 단어 경계를 확인하고('SIL'이 'SILVER'에 걸리지 않게), 한글 용어는 뒤에 조사가 붙어도 찾는다. 찾은 용어의 설명을 "다음은 우리 회사에서 쓰는 용어 뜻입니다" 아래에 붙인다. AI가 사내 약어를 엉뚱하게 해석하는 것을 막아 정확도를 높이는 장치다(심사 기준 "정확성 고려").

**기본 프롬프트 팩 8종 (`resources/prompts.json`, 빌더가 초안을 쓰고 사용자가 다듬는다)**

| 이름 | 그룹 | 가명 기본값 | 내용 |
|---|---|---|---|
| 회의록 정리 | 회의 | 되돌리기 | 결정 사항·담당자·기한·후속 업무 표 |
| 주간보고 초안 | 회의 | 되돌리기 | 업무 기록 → 회사 주간보고 형식 |
| 메일·문의 요약과 회신 초안 | 문서 | 되돌리기 | 핵심·필요한 대응·회신 초안 |
| 문장 다듬기 | 문서 | 되돌리기 | AI 티 나는 표현·반복을 줄이고 업무 문체로 |
| 요구사항 → 테스트 케이스 | 검증 | 되돌리기 | 정상·경계·예외로 나눈 표, 요구사항 ID 추적 |
| 정적분석 위반 분석·소명 초안 | 검증 | 되돌리기 | 출품 ②와 같은 원문 |
| 표준·규격 조항 찾기 | 조사 | 끔 | 출품 ③과 같은 원문. 공개 표준이라 가릴 것이 없음 |
| 협업 문서 요약(실명 유지) | 문서 | 끔 | 결과에 실명이 그대로 필요할 때의 예시 |

모든 프롬프트는 "모르면 모른다고 쓰고 추측하지 말 것", "결과는 사람이 검토할 초안"을 포함하고, 출력 형식(표·목록)을 정해 둔다.

**기준 예시 문서:** 종류별로 잘 쓴 문서 1개를 로컬에 둔다(4,000자 이하 권장, 넘으면 경고). 설정에서 붙여넣어 저장한다. 서버가 없으므로 PC 밖으로 나가지 않는다.

**AI 대상**
```ts
interface AiTarget { id: string; name: string; url?: string; exePath?: string; windowTitleIncludes?: string[] }
```
- 기본 목록: Claude(https://claude.ai), ChatGPT(https://chatgpt.com), Gemini(https://gemini.google.com), "복사만"(아무것도 열지 않음). 사용자가 사내 LLM 주소나 앱을 추가·삭제할 수 있다.
- 기본 대상은 온보딩에서 고르고, 템플릿별·실행별로 바꿀 수 있다.
- (Should) `windowTitleIncludes`로 이미 열린 AI 창을 찾으면 새로 열지 않고 그 창을 앞으로 가져와 Ctrl+V까지 해 준다.

**완료 기준**
- 메모장의 가짜 회의 메모를 선택 → 단축키 → "회의록" → Enter까지 5초 안에 끝나고, 클립보드에 가명 처리된 최종 프롬프트가 들어가며 기본 AI 대상이 열린다.
- 입력 글에 "MC/DC가"가 있으면 `{{terms}}`에 MC/DC 설명이 들어가고, 'SILVER'에는 SIL이 걸리지 않는다.
- 템플릿 파일을 고치면 앱을 다시 켜지 않아도 반영된다.

## 8. F2 가명 처리 (켜기/끄기)

사내에서 Claude·ChatGPT를 쓸 때 협업 문서처럼 고객사명·IP·경로가 결과에 그대로 나와야 하는 경우도 있고, 가려야 하는 경우도 있다. 그래서 상황마다 바꿀 수 있게 한다.

**모드 (전체 기본값 + 템플릿별 기본값 + 실행할 때 바꾸기)**

| 모드 | AI로 보내는 글 | AI 답을 되돌릴 때 | 쓰는 때 |
|---|---|---|---|
| 끔 | 원문 그대로 | 해당 없음 | 결과에 실명이 필요하고 회사가 허용한 AI일 때 |
| 가명 후 되돌리기 (기본) | `CLIENT_A`, `IP_1`… | 원래 이름으로 되돌림 → 결과물에 실명 포함 | AI에는 감추고 결과물에는 실명이 필요할 때 |
| 결과에서 빼기 | `고객사A`, `[IP 주소]`… | 되돌리지 않음 → 결과물에도 없음 | 결과물에 고객사 정보가 남으면 안 될 때 |

- 우선순위: 실행할 때 고른 값 > 템플릿 기본값 > 전체 기본값.
- 지금 모드는 팔레트 상태 표시줄, 확인 화면, 트레이 툴팁에 항상 보인다. **끔일 때는 주황색으로 "가명 처리 꺼짐 — 원문 그대로 복사됩니다"**를 확인 화면에 띄운다.
- 단독 명령: "선택한 글 가명 처리"(템플릿 없이 지금 모드로 처리해 클립보드에), "가명 되돌리기", "가명 처리 모드 바꾸기".

**분류별 켜기/끄기 (설정, 기본은 모두 켬)**
- 사전 기반: 고객사, 프로젝트, 인물, 시스템
- 패턴 기반: IP(IPv4, 옥텟 검사, /CIDR·:포트 포함), 경로(`C:\…`, `\\서버\공유`, 따옴표 안 공백 포함 경로), 이메일, 전화번호(010, 02, 0xx, 070, 15xx, +82), 사내 URL(설정한 사내 도메인)
- 확인 화면에서는 감지된 항목마다 켜고 끌 수 있다(이번 실행에만 적용).

**사전 (`masking-dictionary.json`, 로컬 전용)**
```ts
interface MaskTerm { id: string; category: 'client' | 'project' | 'person' | 'system'; canonical: string; aliases: string[]; exactOnly?: boolean }
```
- 한글·영문·약어·이메일 도메인을 별칭으로 둔다. 설정 화면에서 편집하고, 따로 내보내기/가져오기 할 수 있다(내보낼 때 "고객사 목록이 들어 있으니 사내에서만 공유하세요" 경고).

**찾기 규칙**
- 다 채운 최종 프롬프트 전체(선택한 글 + 용어 설명 + 기준 예시)에 적용한다.
- 정규화는 §9 F3과 같은 규칙(NFC + 전각 접기 + 소문자, NFKC 금지).
- 왼쪽부터 가장 긴 것, 겹치지 않게. 한글 이름은 뒤에 조사가 붙으므로 한글 연속 구간의 앞부분으로 찾는다("현대차에서"). 영문 이름은 대소문자를 무시하되 앞뒤가 영문·숫자가 아닐 때만('LG'가 'LGPL'에 걸리지 않게). `exactOnly`면 정확히 같을 때만.

**표기**
- 되돌리기 모드: ASCII 토큰 `CLIENT_A`, `PROJECT_A`, `PERSON_A`, `SYSTEM_A`, `IP_1`, `PATH_1`, `EMAIL_1`, `PHONE_1`, `URL_1`. 원문에 이미 같은 표기가 있으면 다음 글자로 넘어간다.
- 빼기 모드: 읽기 쉬운 표기 `고객사A`, `프로젝트A`, `담당자A`, `시스템A`, `[IP 주소]`, `[파일 경로]`, `[이메일]`, `[전화번호]`, `[사내 URL]`. 표기는 설정에서 바꿀 수 있다.
- 프롬프트 맨 위에 한 줄을 붙인다.
  - 되돌리기: "CLIENT_A, IP_1 같은 표시는 가린 이름입니다. 바꾸거나 풀어 쓰지 말고 그대로 써 주세요."
  - 빼기: "'고객사A', '[IP 주소]' 같은 표시는 가린 정보입니다. 실제 이름을 추측하지 말고 표시 그대로 써 주세요."

**대응표와 되돌리기**
- 같은 원문은 같은 토큰으로. 대응표는 main 프로세스 메모리에 8시간(설정 가능) 하나만 두고, 그동안 여러 프롬프트에서 같은 토큰을 쓴다. 디스크에 저장하지 않는다.
- 되돌리기: 클립보드 글에서 토큰을 찾되 대소문자·공백·`_`/`-`·괄호가 조금 바뀌어도 찾는다. 이름을 되돌린 뒤 바로 뒤 조사를 원래 이름에 맞게 다시 고른다(`josa.pick`, 영문·숫자로 끝나는 이름은 읽는 소리 표: L·M·N·R, 0·1·3·6·7·8은 받침 있음).
- 대응표에 없는 토큰(AI가 지어낸 `CLIENT_C` 등)이나 남은 토큰이 있으면 복사 전에 알린다.
- 되돌린 글을 클립보드에 쓸 때는 Windows 클립보드 기록·클라우드 동기화 제외 표시(`ExcludeClipboardContentFromMonitorProcessing`)를 함께 쓴다(Electron 45에서 되는지 검증 대상).
- 빼기 모드에서는 대응표를 남기지 않는다.

**(Should 1) 파일 가명 처리:** 팔레트 명령 "파일 가명 처리" 또는 팔레트에 파일을 끌어다 놓기 → 텍스트를 뽑아 지금 모드로 처리 → `<원본이름>.masked.md`를 같은 폴더(설정 가능)에 저장하고 탐색기에서 보여 준다. 사용자는 이 사본을 AI에 첨부한다. txt·md·csv·docx(mammoth)·xlsx(exceljs, 시트별 표)를 먼저, pdf(pdfjs-dist)·pptx·hwpx(XML 텍스트)를 다음에 지원한다. 20MB 넘는 파일은 거절. 구형 .hwp는 지원하지 않고 "HWPX나 PDF로 저장해 주세요"로 안내.

**완료 기준**
- 예시 "현대차에서 받은 SRS를 LIG넥스원는 10.0.3.15의 \\\\fs01\\proj 폴더에 올림"이
  - 끔: 그대로 복사된다(주황 경고 표시).
  - 되돌리기: `CLIENT_A에서 받은 SRS를 CLIENT_B는 IP_1의 PATH_1 폴더에 올림`이 되고, 되돌리면 "현대차에서 … LIG넥스원은 10.0.3.15의 \\\\fs01\\proj"로 이름과 조사까지 돌아온다.
  - 빼기: `고객사A에서 받은 SRS를 고객사B는 [IP 주소]의 [파일 경로] 폴더에 올림`이 되고 되돌리기 대상이 없다.
- 분류 하나(예: IP)를 끄면 그 분류만 원문으로 남는다.
- 템플릿 기본값이 "끔"인 프롬프트는 전체 기본값이 "되돌리기"여도 끔으로 시작하고, 실행 화면에서 바꿀 수 있다.
- 가명 처리 단위 테스트(Vitest): 조사, 영문 경계, 겹침, 토큰 충돌, 관대한 되돌리기, 지어낸 토큰 경고, 분류별 끄기, 모드 우선순위.

## 9. F3 Sure-Wiki (로컬 용어 사전)

**용어 항목**
```ts
interface GlossaryEntry {
  id: string              // uuid v4
  term: string            // "MC/DC" (1~60자)
  aliases: string[]       // ["MCDC", "변경 조건/결정 커버리지"]
  definition: string      // 1,000자 이하, 줄바꿈 허용
  example?: string        // 사용 예, 500자 이하
  links: { title: string; url: string }[] // 5개 이하
  tags: string[]          // 5개 이하
  author?: string         // 닉네임(선택)
  source: 'builtin' | 'user' | 'imported'
  updatedAt: string
  version: number
}
```
- 기본 용어 팩(`resources/glossary.json`, 약 100개)은 설치 파일에 들어간다. 사용자가 고치면 같은 id의 사용자본이 우선한다.
- 같은 용어가 여러 뜻일 수 있으므로(SIL = Safety Integrity Level / Software-in-the-Loop) 중복을 막지 않는다. 추가할 때 정규화 키가 같은 항목이 있으면 먼저 보여 주고 "그래도 새로 추가"를 고르게 한다.

**용어 팩 나누기 (서버 대신)**
- "용어 팩 내보내기": 선택한 용어(기본은 내가 추가·수정한 것)를 `sure-mate-용어팩-YYYYMMDD.json`으로 저장. 형식: `{ format: 'sure-mate-glossary', version: 1, exportedAt, entries: [...] }`.
- "용어 팩 가져오기": 미리 보기(새 용어 N · 바뀐 용어 N · 이름이 겹치는 용어 N) → 확인. 같은 id는 `updatedAt`이 새로운 쪽, 다른 id인데 정규화 키가 같으면 둘 다 두고 표시한다.
- 게시글 댓글·팀 공유 폴더로 팩을 주고받는 방법을 사용 안내에 쓴다.

**검색 (로컬)**
- 정규화: NFC + 전각→반각(U+FF01~FF5E, U+3000) + 소문자. **NFKC는 쓰지 않는다**(초성 'ㅈㅈㅂㅅ'이 다른 문자로 바뀌어 초성 검색이 깨진다).
- 불러올 때 항목마다 미리 계산: 정규화 문자열, 토큰(공백·`-_/.,:()·`와 영문/숫자↔한글 경계로 분리), compact(토큰을 붙인 것, 'C++'·'C#'처럼 1글자 이하로 줄면 원형 유지), 자모(`disassemble`), 초성(`getChoseong`), 영문 자판 키(`convertHangulToQwerty`).
- 점수 단계: 용어 compact 일치 1000(별칭 950) > 앞부분 일치 900(별칭 850) > 토큰 일치·앞부분 800 > 초성 일치 750·앞부분 700·포함 600 > 자모 앞부분 650(치는 중인 음절 '간'→가나) > 한영 오입력 앞부분 600('rjator'→검색) > compact 포함 500 > 자모 포함 450 > 자모 단위 오타 300−100×거리(검색어 자모 4~7개면 거리 1까지, 8개 이상이면 2까지, 앞 단계 결과가 5개 미만일 때만) > 설명 본문 포함 100. 동점이면 학습 연결, 최근·자주 쓴 항목, 짧은 용어 순.
- 같은 랭커를 프롬프트·상용구·워크스페이스·명령 검색에도 쓴다.

**보기·추가·수정:** 상세(용어, 별칭, 설명, 사용 예, 링크, 태그, 출처) + [설명 복사] [수정] [링크 열기]. 결과가 없으면 "이 용어를 아시나요? 직접 추가하기"(입력한 말을 미리 채움). 링크는 http/https만 연다.

**선택 텍스트 사이드 패널**
- 단축키(첫 실행 때 고름, 제안 `Ctrl+Alt+W`) → 선택한 글을 가져와(§10의 "선택 텍스트 가져오기") 검색 → 사이드 패널에 가장 맞는 항목 1개 + 후보 2개. 선택한 글이 20자를 넘으면 글 안에 나오는 용어를 모두 찾아 목록으로 보여 준다.
- 창 옵션: `show:false, frame:false, focusable:false, type:'toolbar', alwaysOnTop:true` + `showInactive()`. 아크릴 대신 불투명(또는 반투명) CSS 배경. 내용이 바뀌면 `moveTop()`.
- 포커스를 뺏지 않는다. 클릭은 받지만 키보드 입력은 못 받으므로 읽기 전용이다. [설명 복사] [고정] [닫기] [팔레트에서 열기]만 두고, 추가·수정은 팔레트에서 한다.
- 자동 숨김(기본 8초, 마우스를 올리면 유지), 고정 버튼.
- 사용자 설정: 표시 모니터(마우스 위치/주/보조/특정 모니터), 가장자리(왼쪽/오른쪽), 위쪽 여백, 너비, 높이(내용에 맞춤/전체), 투명도, 항상 위 수준, 자동 숨김 시간. 설정 화면에서 바꾸면 바로 미리 보기로 보여 준다.
- 위치는 모니터별로 DIP 단위(가장자리+여백+크기)로 저장하고, 모니터가 바뀌면(display-added/removed/metrics-changed) 다시 적용한다. 배율이 다른 모니터로 옮긴 뒤에는 크기를 한 번 더 맞추고 `getBounds()`로 확인한다.

**완료 기준**
- "ㅈㅈㅂㅅ", "정적분삭", 영문 모드로 친 "wjdwjrqnstjr", "mcdc"가 각각 '정적분석'·'MC/DC'를 맨 위로 찾는다.
- PC A에서 내보낸 용어 팩을 PC B에서 가져오면 미리 보기 숫자대로 반영된다.
- 사이드 패널을 띄워도 원래 창의 포커스가 바뀌지 않는다.

## 10. 선택 텍스트 가져오기와 붙여넣기 (공통, 전역 훅 없이 koffi로)

**가져오기**
1. 단축키를 누른 사용자의 Ctrl·Alt·Shift가 떼어질 때까지 기다린다(최대 500ms). 그대로 보내면 Ctrl+C가 Ctrl+Alt+C로 섞인다.
2. 대상이 터미널·콘솔이거나 관리자 권한 창이면 시도하지 않고 "글을 복사한 뒤 다시 눌러 주세요"로 안내한다(터미널에서 Ctrl+C는 실행 중단이다).
3. 클립보드 순번(GetClipboardSequenceNumber)을 기억하고, 텍스트·HTML·RTF·PNG만 백업한다.
4. SendInput으로 Ctrl+Insert를 보내고, 순번이 안 바뀌면 Ctrl+C를 보낸다. 순번이 바뀔 때까지 최대 500ms 기다린다.
5. 글을 읽고, 그사이 사용자가 따로 복사하지 않았을 때만 백업한 내용을 되돌린다. 엑셀·HWP 서식 같은 복잡한 형식은 되돌릴 수 없다는 한계를 도움말에 적는다.
6. 선택한 글이 없으면 클립보드 글을 입력 후보로 보여 준다.
- 전역 키보드·마우스 훅 라이브러리(selection-hook 등)는 회사 보안 프로그램(EDR)에 키로거처럼 보일 수 있어 쓰지 않는다.

**붙여넣기 (상용구, 되돌린 글)**
1. 팔레트를 열 때 저장한 대상 HWND를 쓴다.
2. 글을 클립보드에 한 번에 쓴다.
3. 팔레트를 숨기고 `SetForegroundWindow(대상)`.
4. 대상이 실제로 앞에 왔는지, 보조키가 떼어졌는지 확인한다.
5. SendInput으로 Ctrl+V.
- 붙여넣기 뒤 클립보드를 자동으로 되돌리지 않는다.
- 관리자 권한 창이거나 원격 데스크톱처럼 붙여넣기가 막히면 "복사했어요, Ctrl+V로 붙여넣으세요" 알림.

## 11. F4 워크스페이스 (창 배치 저장·복원)

사용자가 좌표를 입력하지 않는다. 원하는 대로 창을 놓은 뒤 "지금 배치 저장"을 누르면 기록되고, 이름으로 불러온다.

**저장할 때**
- 대상 창: 보이는 최상위 창 중 제목이 있고, 도구 창·가려진(cloaked) 창·Sure-Mate 자신의 창이 아닌 것
- 창마다 기록: 실행 파일 이름(EXCEL.EXE), 제목, 클래스, 상태(보통/최대화), 작업 영역 기준 상대 위치(x, y, w, h를 0~1 비율로), 모니터 역할
- 모니터 구성 지문: 모니터 수, 각 해상도·배율·상대 위치, 내장 디스플레이 여부를 정렬해 만든 키

**데이터 모델 (제안)**
```ts
type MonitorRole = 'primary' | 'secondary' | 'internal' | { key: string }

interface WindowRule {
  id: string
  enabled: boolean
  match: { exe: string; titleIncludes?: string; titleRegex?: string; className?: string }
  target: { monitor: MonitorRole; rect: { x: number; y: number; w: number; h: number }; state: 'normal' | 'maximized' }
  order: number // z-순서
}

interface Workspace {
  id: string
  name: string            // "QA 모드"
  aliases: string[]       // ["qa", "시험", "테스트"]
  hotkey?: string
  layouts: Record<string /* 모니터 구성 지문 */, WindowRule[]>
  updatedAt: string
}
```

**불러올 때**
1. 현재 모니터 구성 지문과 같은 배치를 쓴다. 없으면 모니터 수가 같은 배치를, 그것도 없으면 역할(주/보조/내장)로 맞춰 옮기고, 없는 모니터의 창은 주 모니터로 보낸다.
2. 창 목록을 한 번 읽고, 규칙마다 실행 파일로 후보를 찾고 제목 규칙으로 고른다. 창 하나는 규칙 하나에만 배정한다(엑셀 창 2개를 제목으로 구분).
3. 최소화·최대화된 창은 먼저 보통 상태로 되돌린 뒤 옮긴다.
4. 배율이 다른 모니터로 옮길 때는 먼저 대상 모니터로 옮기고, 창이 스스로 크기를 바꾼 뒤 최종 크기를 한 번 더 맞춘다.
5. 보이지 않는 테두리(DWMWA_EXTENDED_FRAME_BOUNDS와 GetWindowRect 차이)를 보정해 창 사이 틈이 생기지 않게 한다.
6. 기록 때 최대화였던 창은 옮긴 뒤 최대화한다.
7. 끝나면 "5개 중 4개 배치, Excel 못 찾음"처럼 결과를 짧게 알린다. 관리자 권한으로 실행된 창은 옮길 수 없으니(UIPI) 건너뛰고 이유를 알린다.

**설정 화면:** 워크스페이스 목록, "지금 배치 저장", 이름·별칭·단축키 편집, 저장된 창 목록(포함 여부, 실행 파일, 제목 규칙, 대상 모니터), 모니터 그림 위 사각형 미리 보기.

**완료 기준**
- 100%·150% 배율이 섞인 모니터 2대에서, 창 3개 이상 배치를 저장하고 흐트러뜨린 뒤 불러오면 각 창이 저장 위치에서 ±10px 안에 놓인다.
- 최소화·최대화 상태였던 창도 제자리로 간다.
- 노트북만 연결된 상태에서 불러오면 남은 모니터로 옮기고 안내한다.
- 같은 프로그램 창 2개가 제목 규칙으로 구분된다.

## 12. F5 상용구

F1과 같은 템플릿 엔진(`kind: 'snippet'`)으로 결함 리포트(`!이슈`), 메일 서명 같은 글을 직전 창에 붙여넣는다(§10 붙여넣기 순서). 상용구에는 가명 처리를 하지 않는다. 기본 상용구 본문은 사용자가 회사 양식에 맞게 채운다.

**완료 기준:** 메모장·Word·HWP에서 `!이슈`를 실행하면 커서 위치에 템플릿이 한 번만 붙는다.

## 13. F6 말하듯 입력 (AI 없이)

단어 목록은 코드에 박지 않고 `intents.json`(기본본은 `resources/`, 사용자가 고칠 수 있음)에 둔다.

1. 정규화(§9와 같은 규칙) → 기호 접두어 확인
2. 끝의 `?!.~`와 군말(좀, 그, 저기, 혹시) 제거
3. 공백을 뺀 문자열 끝에서 요청 어미를 긴 것부터 최대 두 번 뗀다. 예: 해주실래요, 해주세요, 해줘, 해봐, 주세요, 줘, 부탁해, 보여줘, 알려줘, 가르쳐줘, 설명해줘, 찾아줘, 검색해줘, 정리해줘, 요약해줘, 뭐예요, 뭔가요, 무엇인가요, 뭐야, 뭐지, 이란, 란, 바꿔줘, 바꿔, 전환해줘, 켜줘, 켜, 꺼줘, 열어줘, 실행해줘, 띄워줘, 불러와줘, 복원해줘, 저장해줘, 만들어줘, 작성해줘, 써줘, 복사해줘, 가려줘, 되돌려줘
4. 영문·숫자와 한글 경계에서 나눈다("MC/DC가" → MC/DC + 가)
5. 조사를 사전에 맞춰 뗀다. 긴 것부터: 으로부터, 에서부터, 으로서, 으로써, 이라는, 라는, 이라고, 라고, 이랑, 랑, 하고, 에게서, 에게, 한테, 에서는, 에서도, 에서, 에는, 에도, 으로는, 로는, 으로, 로, 까지, 부터, 처럼, 보다, 마다, 이나, 나, 이란, 란, 의, 은, 는, 이, 가, 을, 를, 와, 과, 도, 만, 에. **떼기 전 원형도 후보로 남기고 동점이면 원형이 이긴다**("정확도"가 "정확"+"도"로 잘리지 않게).
6. 의도 단어
   - 프롬프트: 정리, 요약, 초안, 작성, 다듬기, 교정, 테스트 케이스, 소명, 조항, 분석, 프롬프트, AI, 클로드, GPT, 제미나이
   - 위키: 뜻, 의미, 정의, 용어, 약어, 풀네임, 뭐야, 이란
   - 워크스페이스 전환: 워크스페이스, 레이아웃, 배치, 화면, 모드, 전환, 바꿔, 켜, 복원, 불러와

7. 후보 점수 = §9 검색 점수 + 의도 가산점 + 학습 가산점. 자동 실행하지 않는다. 후보를 구역별로 보여 주고 Enter로 맨 위를 실행한다.
8. (Should) 맨 위가 아닌 후보를 고르면 "이 문장 기억하기"를 제안한다. 학습 내용은 로컬에만 두고, 내보내기에는 사용자가 따로 고를 때만 넣는다.

## 15. F8 배포

- electron-builder NSIS 원클릭, 사용자 단위 설치(`oneClick:true, perMachine:false`, `%LOCALAPPDATA%\Programs`, 관리자 권한 없음), x64만, `electronLanguages: ['ko','en-US']`. 파일명 `Sure-Mate-Setup-<버전>.exe`. 포터블 빌드는 만들지 않는다.
- 앱 정보·설치 파일 게시자·저작권 표기에 실명을 넣지 않는다("Sure-Mate").
- 설치 파일은 100MB 안팎이 예상된다. 게시판 첨부 용량을 미리 확인한다.

- 서명이 없는 동안 트레이 GUID는 지정하지 않는다.
