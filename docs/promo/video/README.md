# 공모전 홍보 영상

`sure-mate-promo.mp4`는 사내 공모전 게시글에 첨부하는 홍보 영상이다.

- 화면: 1920×1080, 30fps, 87.3초
- 소리: 합성 음악과 효과음(내레이션 없음)
- 대표 이미지: `sure-mate-promo-poster.png`

한 직원(가상 인물 김가상)의 하루를 시간 순서로 따라가며, 업무 중 실제로 발생하는 상황에서 Sure-Mate 주요 기능을 사용하는 장면을 보여 준다.

## 장면 구성

| 영상 시각 | 장면 | 보여 주는 기능 |
|---|---|---|
| 0:00 | 처음 카드 | 이름과 한 줄 소개 |
| 0:03 | 09:00 출근 | 팔레트에 '출근' 입력 → Ttree 열기(실제 Ttree 화면) |
| 0:11 | 09:05 창 정리 | Ctrl+Alt+1로 저장한 창 배치 불러오기 |
| 0:18 | 10:30 회의록 | 메모 선택 → '회의록' → 확인 화면의 가명 처리 → AI 채팅에 붙여넣기 |
| 0:35 | 10:40 보고서 | AI가 작성한 글 복사 → '가명 되돌려줘' → 보고서에 붙여넣기 |
| 0:44 | 13:00 용어 | 'MC/DC' 선택 → Ctrl+Alt+W 용어 카드 |
| 0:51 | 14:30 결함 등록 | '!이슈' → 결함 리포트 양식 |
| 0:58 | 15:19 이석 미리 알림 | 서류를 읽는 사무실 그림 → Ttree '이석체크간격 : 20분' → 말랑 메이트가 2분 전에 깨워 알림 → 마지막 30초 초 세기 → 마우스를 움직이면 닫힘 |
| 1:08 | 16:00 지나가는 동료 | 사무실 그림(뒤로 동료가 지나감) → 키보드 Ctrl+Alt+H → 화면 감추기로 업무 창만 남기기, 한 번 더 눌러 되돌리기 |
| 1:16 | 17:10 휴식 | 말랑 메이트의 쉬어 가기 말 |
| 1:21 | 끝 카드 | 기본 단축키, 첨부 파일 이름, 설치 안내 |

자막은 홍보 게시글과 같은 해요체를 사용한다.

## 실제 화면과 영상용으로 그린 화면

**실제 화면(앱 코드로 그린 캡처)**

- 대상: 팔레트(입력 단계별 검색 결과 포함), 확인 화면, Sure-Mate 바, 용어 카드, 말랑 메이트와 말풍선(이석 미리 알림과 초 세기 포함)
- 방법: `capture.mjs`가 렌더러 미리 보기 빌드(`desktop/src/renderer/src/preview`)로 실제 React 컴포넌트를 그린 뒤, 배경 없이 2~3배 해상도로 캡처한다.

**앱 코드로 계산한 값(`fixtures.mjs`, `capture.mjs`)**

- 팔레트 항목: `buildPaletteItems`(설치된 사내 업무 프로그램 명령 포함)
- 확인 화면 미리 보기: `fillTemplate`과 `createMaskingService`의 가명 처리 결과
- 보고서에 붙여넣은 글: 가명 처리 서비스의 `unmask` 결과
- 말풍선 문구: `petBubbleText`, 이석 미리 알림 `petAwayLine`·`petAwayCountdownLine`(표정·소품은 `awayReaction`에 가명 처리 켬의 선글라스)
- Sure-Mate 창 위치: `palettePosition`, `barRect`, `flyoutCardRect`

**실제 Ttree 화면(`scene/assets/`)**

- `ttree-0900.png`(09:00 출근), `ttree-1519.png`(15:19 이석 기준): 150% 배율 캡처(737×1188)를 491×792 크기로 그린다. 파일이 없으면 영상용으로 그린 Ttree 창을 쓴다.

**영상용으로 그린 화면(`scene/`)**

- 바탕화면, 작업 표시줄, 다른 앱 창(코드 편집기, 표 편집기, 메모장, 문서 편집기, PDF 보기, 브라우저, 사내 메신저)
- 사무실 그림(`scene/office.js`, 평면 일러스트): 의자 뒤에서 본 사용자, 지나가는 동료, 키보드. 인물은 얼굴을 그리지 않은 가상 인물이다.
- 자막, 누른 키, 마우스 커서, 화면 확대, 강조 테두리

다른 앱 창은 특정 제품의 로고와 화면을 따라 그리지 않는다(Ttree만 사용자 요청으로 실제 화면을 쓴다, 아래 결정 사항). AI 채팅 화면은 설정에 추가한 가상 AI 대상('AI 채팅', ai.example.com)으로 구성한다.

인물·고객사·문서 이름은 모두 가상 이름이다(김가상, 이예시, 가상자동차, XY방산).

음악과 효과음은 `audio.mjs`가 직접 합성한다. 녹음 파일을 사용하지 않으므로 저작권 확인 대상이 없다.

## 다시 만들기

필요한 것은 다음과 같다.

- Node 22 이상
- Chrome 또는 Edge(경로가 다르면 환경 변수 `CHROME`에 실행 파일 경로 지정)
- ffmpeg(경로가 다르면 환경 변수 `FFMPEG`에 지정)
- `desktop/node_modules`(미리 보기 빌드에 사용)
- 인터넷 연결(Google Fonts의 Jua, IBM Plex Mono 글꼴)

저장소 루트에서 다음 명령을 실행한다. 소요 시간은 약 10분이고 대부분 프레임 렌더링 시간이다.

```bash
node docs/promo/video/build.mjs
```

- 앱 화면의 문구가 바뀌면(예: 사내 메신저·Ttree 열기 명령의 제목과 부제) 같은 명령을 다시 실행한다. 캡처와 계산 값은 실행할 때의 코드로 다시 생성된다.
- 캡처를 다시 생성하지 않고 장면과 소리만 다시 만들 때는 `--skip-capture`를 추가한다.
- 장면 시각, 자막, 키, 창 배치는 `scene/scene.js`에 정의한다.
- 한 장씩 그리기가 느린 PC(Windows 노트북에서 영상 1초에 40초 넘게 걸렸다)에서는 구간을 나눠 동시에 그린 뒤 이어 붙인다. 구간마다 `node render.mjs --from=0 --to=15 --out=.cache/seg-0.mp4 --profile=0`처럼 Chrome 사용자 폴더(`--profile`)를 따로 주고, `ffmpeg -f concat -safe 0 -i <목록> -c copy .cache/video.mp4`로 붙인 다음 `audio.mjs`와 build.mjs의 소리 합치기·대표 이미지 단계를 그대로 실행한다(6구간 동시 약 10분).
- 특정 시각의 한 장면만 확인할 때는 `node docs/promo/video/render.mjs --stills=20.5,47`을 실행한다. 결과는 `.cache/stills/`에 저장된다.
- 렌더링은 GPU를 사용하지 않고(`--disable-gpu`), Chrome과는 파이프로 통신하므로 네트워크 포트를 열지 않는다.
- 중간 결과(`.cache/`)는 저장소에 포함하지 않는다.

## 결정 사항(2026-11-13)

- **영상 제작 방식:** 실제 시연 녹화 대신 실제 화면 캡처와 영상용 바탕화면을 합성한다. 시연을 녹화하지 않아도 앱이 실제로 표시하는 화면을 그대로 보여 줄 수 있고, 앱 문구가 바뀌면 같은 명령으로 영상을 다시 생성할 수 있다.
- **Remotion을 사용하지 않는 이유:** Remotion은 직원 4명 이상인 회사에 유료 라이선스를 요구한다. 브라우저 화면을 프레임 단위로 캡처하는 방식은 Chrome과 ffmpeg만 사용한다.
- **영상 생성 서비스를 사용하지 않는 이유:** 크레딧이 소모되고 화면 자료가 외부로 전송되며, 생성된 화면은 실제 앱 화면이 아니다.
- **실제 Ttree 화면(사용자 요청):** 동료가 바로 알아보도록 그린 창 대신 실제 Ttree 화면을 쓴다. 개발 PC의 Ttree 창을 키·클릭 없이 PrintWindow로 찍고, 이름·직급·팀은 가상 인물(김가상 책임 / 시험검증2팀)로, 날짜·시각·근무 기록은 영상 속 월요일에 맞는 가상 값으로 바꿔 그린다(바꾼 칸 밖의 픽셀은 원본 그대로, 글꼴은 Ttree와 같은 Muli·맑은 고딕). 원본 캡처는 저장소에 넣지 않고 지운다. 창 제목 줄의 근무시간 관리 솔루션 이름은 사내 공모전이라 그대로 둔다.
- **내레이션을 포함하지 않는 이유:** 목소리로 작성자를 식별할 수 없어야 한다. 소리를 끈 상태에서도 자막과 키 표시만으로 내용을 파악할 수 있다.
