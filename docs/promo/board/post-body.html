회의 메모를 고르고 단축키 한 번이면, 우리 업무에 맞춘 프롬프트가 만들어지고 고객사·사람 이름·IP는 가명으로 바뀐 채 쓰던 AI가 열려요.
AI가 쓴 답은 '가명 되돌리기' 한 번으로 원래 이름으로 돌아와요. 혼자 쓰기 아까워서 동료 PC에도 관리자 권한 없이 바로 깔리게 만들었어요.

【이미지 넣기: 01-intro.png】

① 어떤 업무에 썼나요

  • 회의가 끝나면 메모를 회의록(결정 사항, 할 일·담당자·기한 표)으로 정리할 때
  • 메일·문의 요약과 회신 초안, 주간보고 초안을 쓸 때
  • 요구사항에서 테스트 케이스를 뽑거나, 정적분석 위반 소명 초안을 쓸 때
  • 고객사 자료를 AI에 붙여넣기 전에 회사·사람 이름과 IP를 하나하나 지우던 일

【이미지 넣기: 03-ai.png】

② 무엇이 좋아졌나요

전에는 메모 복사 → 프롬프트 작성 → 이름·IP 지우기 → AI 사이트 열기 → 붙여넣기 → AI 답에서 이름을 다시 손으로 되돌리기를 매번 했어요.
지금은 글 선택 → Ctrl+Alt+Space → '회의록' 입력 후 Enter → 바뀐 이름 확인 후 Enter → AI 창에 Ctrl+V로 끝나요.

  • 이름을 지우다 하나 빠뜨리는 실수가 줄어요. IP·경로·메일·전화번호는 자동으로, 고객사·사람 이름은 가명 사전에 적어 둔 대로 찾아 바꾸고, 무엇이 바뀌는지 보내기 전에 목록으로 보여 줘요.
  • 사내 약어(MC/DC, ASIL, HILS 등)의 뜻을 프롬프트에 같이 보내서 AI가 약어를 엉뚱하게 해석하는 일이 줄어요.
  • 매번 새로 쓰던 프롬프트를 고르기만 하면 되고, 프롬프트에 결과 형식(표·목록)을 정해 두어 매번 비슷한 형식으로 결과를 받아요.

【선택: 직접 잰 시간이 있으면 이 줄을 바꿔 넣고, 없으면 지우기. 예) 작성자 1인 측정 — 회의록 1건 정리 ○분 → ○분】

③ AI를 어떻게 활용했나요

  • 업무용 프롬프트 9종: 회의록 정리, 주간보고 초안, Ttree 근무 기록 → 주간보고, 메일·문의 요약과 회신 초안, 문장 다듬기, 요구사항 → 테스트 케이스, 정적분석 위반 분석·소명 초안, 표준·규격 조항 찾기, 협업 문서 요약. 프롬프트마다 역할, 결과 형식, 지킬 것('입력에 없는 내용은 만들지 않기', 모르면 '모름', 확인할 곳은 [확인 필요])을 넣어 두었어요.
  • 정확도 장치: 글에 나온 사내 용어의 설명을 프롬프트에 자동으로 붙여요.
  • 보안 장치: 보내기 전에 이름과 IP·경로를 CLIENT_A, IP_1 같은 가명으로 바꾸고, AI가 쓴 글은 원래 이름으로 되돌려요. 가명 사전과 대응표는 이 PC에만 있고, 앱은 인터넷에 접속하지 않아요.
  • 사람이 마지막 확인: 보내기 전에 확인 화면에서 최종 프롬프트와 바뀐 이름을 보고, 이번만 그대로 보낼 이름은 끌 수 있어요.
  • 어떤 AI든: 앱이 AI를 직접 부르지 않아요. 프롬프트를 클립보드에 넣고 회사에서 허용한 AI(Claude, ChatGPT, Gemini 등)를 열어 줘요. API 키도 비용도 필요 없어요.

함께 들어 있는 업무 비서 기능

  • 창 배치 저장·불러오기: 회의 뒤 흐트러진 창을 단축키 한 번에 저장한 자리로 되돌려요("보고서 모드로 바꿔줘"처럼 말로 해도 돼요)
  • 화면 감추기(Ctrl+Alt+H): 자리에 손님이 오면 업무 창만 남기고 다른 고객사 문서·메신저를 내려요
  • 용어 카드(Ctrl+Alt+W): 모르는 사내 용어를 고르면 뜻이 화면 오른쪽 바 옆에 떠요
  • 상용구: 팔레트에 '!이슈'를 치면 결함 리포트 양식이 붙어요
  • 사내 메신저·Ttree 열기: '출근', '휴가 신청'처럼 쳐도 열려요
  • Ttree 이석 미리 알림: 서류를 읽거나 회의 화면을 보느라 입력이 없을 때, 이석으로 잡히기 2분 전에 말랑 메이트가 알려 주고 마지막 30초는 초를 세요. 알려 주기만 하고 입력을 흉내 내지는 않아요
  • 말랑 메이트: 가명 처리 상태를 알려 주고, 한 시간쯤 일하면 쉬어 가자고 말을 걸어요

사용법

  1. 첨부한 Sure-Mate-Setup-0.1.0.exe를 내려받아 실행해요. 관리자 권한은 필요 없어요.
  2. 'Windows의 PC 보호' 파란 창이 뜨면 [추가 정보] → [실행]을 눌러요. 서명이 없는 사내 도구라서 뜨는 창이에요.
  3. 첫 실행 안내 세 화면을 따라가고, 트레이 메뉴의 '따라 해 보기'로 30초 연습을 해 보세요.
  4. 가명으로 바꿀 우리 고객사·프로젝트 이름은 팔레트에서 '가명 사전 열기'로 적어 두세요.
  5. 기본 단축키: Ctrl+Alt+Space 팔레트(단축키로 여는 명령 창), Ctrl+Alt+W 용어 카드, Ctrl+Alt+H 화면 감추기

동작 환경: Windows 64비트 · 지우는 법: 설정 → 앱 → Sure-Mate → 제거
