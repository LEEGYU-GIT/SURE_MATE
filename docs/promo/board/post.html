Sure-Mate AI 프롬프트 · 가명 처리 · 업무 비서  /  v0.1.0  /  Windows
회의록 정리부터 AI에 붙여넣기까지, 반복 작업을 줄여 본 이야기
선택하고, 단축키, 회의록 정리.
고객사 이름은 AI가 몰라요.

회의 메모를 고르고 단축키 한 번이면, 우리 업무에 맞춘 프롬프트가 만들어지고 고객사·사람 이름·IP는 가명으로 바뀐 채 쓰던 AI가 열려요.

AI가 쓴 답은 ‘가명 되돌리기’ 한 번으로 원래 이름으로 돌아와요. 혼자 쓰기 아까워서 동료 PC에도 관리자 권한 없이 바로 깔리게 만들었어요.

이렇게 끝나요
1쓰던 창에서 회의 메모 선택
2Ctrl + Alt + Space
3‘회의록’ 입력 후 Enter
4바뀐 이름 확인 후 Enter
5열린 AI 창에 Ctrl + V
보낼 글  가상자동차 시험 결과를 10.0.3.15에 올렸어요
AI에 가는 글  CLIENT_A 시험 결과를 IP_1에 올렸어요
아래 영상은 실제 Sure-Mate 화면에 가상 데이터를 넣어 만든 87초 사용 장면이에요. 인물·고객사 이름은 모두 가상이에요.

【영상 넣기: sure-mate-promo.mp4 — 이 줄을 지우고 영상을 넣어 주세요】

1어떤 업무에 썼나요
회의가 끝나면
메모를 회의록(결정 사항, 할 일·담당자·기한 표)으로 정리할 때
메일과 보고를 쓸 때
메일·문의 요약과 회신 초안, 주간보고 초안을 쓸 때
검증 업무에서
요구사항에서 테스트 케이스를 뽑거나, 정적분석 위반 소명 초안을 쓸 때
AI에 붙여넣기 전에
고객사 자료에서 회사·사람 이름과 IP를 하나하나 지우던 일
2무엇이 좋아졌나요
전에는 매번
메모 복사 → 프롬프트 작성 → 이름·IP 지우기 → AI 사이트 열기 → 붙여넣기 → AI 답에서 이름을 다시 손으로 되돌리기
지금은
글 선택 → Ctrl+Alt+Space → ‘회의록’ 입력 후 Enter → 바뀐 이름 확인 후 Enter → AI 창에 Ctrl+V로 끝나요
  • 이름을 빠뜨리는 실수가 줄어요. IP·경로·메일·전화번호는 자동으로, 고객사·사람 이름은 가명 사전에 적어 둔 대로 찾아 바꾸고, 무엇이 바뀌는지 보내기 전에 목록으로 보여 줘요.
  • AI가 약어를 헷갈리지 않아요. 사내 약어(MC/DC, ASIL, HILS 등)의 뜻을 프롬프트에 같이 보내요.
  • 결과 형식이 매번 같아요. 매번 새로 쓰던 프롬프트를 고르기만 하면 되고, 결과 형식(표·목록)을 정해 두었어요.
3AI를 어떻게 활용했나요
업무용 프롬프트 9종
회의록 정리주간보고 초안Ttree 근무 기록 → 주간보고메일·문의 요약과 회신 초안문장 다듬기요구사항 → 테스트 케이스정적분석 위반 분석·소명 초안표준·규격 조항 찾기협업 문서 요약
프롬프트마다 역할, 결과 형식, 지킬 것(‘입력에 없는 내용은 만들지 않기’, 모르면 ‘모름’, 확인할 곳은 [확인 필요])을 넣어 두었어요.
정확도 장치
글에 나온 사내 용어의 설명을 프롬프트에 자동으로 붙여요.
보안 장치
보내기 전에 이름과 IP·경로를 CLIENT_A, IP_1 같은 가명으로 바꾸고, AI가 쓴 글은 원래 이름으로 되돌려요. 가명 사전과 대응표는 이 PC에만 있고, 앱은 인터넷에 접속하지 않아요.
사람이 마지막 확인
보내기 전에 확인 화면에서 최종 프롬프트와 바뀐 이름을 보고, 이번만 그대로 보낼 이름은 끌 수 있어요.
어떤 AI든
앱이 AI를 직접 부르지 않아요. 프롬프트를 클립보드에 넣고 회사에서 허용한 AI(Claude, ChatGPT, Gemini 등)를 열어 줘요. API 키도 비용도 필요 없어요.
함께 들어 있는 업무 비서 기능
모두 단축키 하나, 또는 팔레트에 말 한마디로 불러요.
창 배치 저장·불러오기
회의 뒤 흐트러진 창을 단축키 한 번에 저장한 자리로 되돌려요. “보고서 모드로 바꿔줘”처럼 말로 해도 돼요.
화면 감추기 Ctrl+Alt+H
자리에 손님이 오면 업무 창만 남기고 다른 고객사 문서·메신저를 내려요.
용어 카드 Ctrl+Alt+W
모르는 사내 용어를 고르면 뜻이 화면 오른쪽 바 옆에 떠요.
상용구 !이슈
팔레트에 ‘!이슈’를 치면 결함 리포트 양식이 붙어요.
사내 메신저·Ttree 열기
팔레트에 ‘출근’, ‘휴가 신청’, ‘메신저 열어줘’처럼 쳐도 열려요.
Ttree 이석 미리 알림
서류를 읽거나 회의 화면을 보느라 입력이 없을 때, 이석으로 잡히기 2분 전에 말랑 메이트가 알려 주고 마지막 30초는 초를 세요. 알려 주기만 하고 입력을 흉내 내지는 않아요.
말랑 메이트
가명 처리 상태를 알려 주고, 한 시간쯤 일하면 쉬어 가자고 말을 걸어요.
설정은 이 PC에만
설정·용어·가명 사전은 모두 이 PC에 저장되고, 앱은 인터넷에 접속하지 않아요.
사용법
1첨부한 Sure-Mate-Setup-0.1.0.exe를 내려받아 실행해요. 관리자 권한은 필요 없어요.
2‘Windows의 PC 보호’ 파란 창이 뜨면 [추가 정보] → [실행]을 눌러요. 서명이 없는 사내 도구라서 뜨는 창이에요.
3첫 실행 안내 세 화면을 따라가고, 트레이 메뉴의 ‘따라 해 보기’로 30초 연습을 해 보세요.
4가명으로 바꿀 우리 고객사·프로젝트 이름은 팔레트에서 ‘가명 사전 열기’로 적어 두세요.
5기본 단축키: Ctrl+Alt+Space 팔레트(단축키로 여는 명령 창), Ctrl+Alt+W 용어 카드, Ctrl+Alt+H 화면 감추기
