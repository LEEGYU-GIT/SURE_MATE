써 보기 전에 궁금한 것

회사 자료를 AI에 보내도 괜찮을까요?
보내기 전에 고객사·IP·경로를 바꿔 주지만, 꼭 회사가 허용한 AI에만 붙여넣어 주세요. 올리면 안 되는 자료는 처음부터 고르지 않는 것이 가장 안전해요.
화면 감추기를 누르면 창이 닫히나요?
닫지 않고 내리기만 해요. 한 번 더 누르면 그대로 돌아와요. 처음에는 모든 창을 내리고, 지금 배치를 화면 감추기에 저장해 두면 그 창들은 남겨요.
단축키를 눌러도 아무 일이 없어요.
다른 프로그램이 같은 조합을 쓰고 있을 수 있어요. 설정 → 단축키에서 빨간 안내를 확인하고 다른 조합으로 바꿔 주세요.
보안 프로그램이 창 제어를 막아요.
그래도 팔레트와 프롬프트, 가명 처리는 클립보드 글로 동작해요. 선택한 글 가져오기와 창 배치만 쓸 수 없다고 알려 드려요.
이석을 막으려고 마우스를 대신 움직이나요?
아니요. 키보드·마우스를 안 쓴 시간을 보고 알려 주기만 해요. 자리에 있는 사람이 직접 움직여야 하고, 자리를 비우면 Ttree가 평소대로 이석을 잡아요.
Ttree나 메신저 내용을 읽나요?
읽지 않아요. 창을 앞으로 가져오기만 해요. 휴가 신청과 근무 기록은 Ttree에서 직접 해요.
말랑 메이트가 신경 쓰여요.
오른쪽 클릭하고 숨기기를 고르세요. 바의 펫 단추로 다시 불러요. 쉬어 가기 말은 설정 → 말랑 메이트에서 끌 수 있어요.
다시 연습해 보고 싶어요.
트레이 메뉴의 ‘따라 해 보기’나 팔레트의 ‘따라 해 보기 (30초)’로 언제든 다시 해 볼 수 있어요.

화면은 어디서 왔나

팔레트·확인 화면·바·용어 카드·말랑 메이트는 실제 앱 화면을 캡처했고, 바탕화면과 다른 앱 창은 영상용으로 그렸어요. Ttree는 동료가 바로 알아보도록 실제 화면을 쓰되, 이름·직급·팀·날짜·근무 기록은 가상 인물 김가상에 맞춰 바꿔 그렸어요. 사무실 장면은 얼굴 없는 평면 그림이고, 인물·고객사·문서 이름은 모두 가상이에요.

게시판에 올리는 법

영상 파일을 게시글 맨 위에 첨부하고 대표 이미지를 썸네일로 써요. 게시판이 영상을 못 붙이면 장면을 6~8초 GIF로 잘라(이석 미리 알림 0:58–1:08, 지나가는 동료 1:08–1:16처럼) 이미지 사이에 넣어요.

영상을 다시 만들 때

  • 앱 문구가 바뀌면 다시 만들기캡처와 자막 값을 그때 코드로 다시 뽑아요(docs/promo/video/README.md). 이 PC는 구간 6개를 동시에 그려 약 10분 걸려요
  • ffmpeg 준비이 PC는 winget으로 설치한 Gyan.FFmpeg를 써요(winget install --id Gyan.FFmpeg -e)
  • Ttree 화면은 가상 값으로 바꾼 두 장만scene/assets의 ttree-0900.png·ttree-1519.png만 저장소에 있어요. 다시 찍으면 실명 줄을 바꾼 뒤 원본은 지워요
  • 알림 끄고 확인다시 만든 뒤 소리를 켜고 처음부터 끝까지 한 번 봐요(음악·효과음 크기, 자막이 다 읽히는지)

게시 전 확인

  • 설치 파일 크기·메모리·CPU를 최종본으로 고치고 이미지 다시 뽑기11/13 게시용 빌드(main 7746542)로 고쳤어요: 설치 파일 약 110MB, 사용 메모리 약 310MB, 가만히 있을 때 CPU 0.2% 안팎
  • 첨부 파일 용량 확인설치 파일(약 110MB)과 영상(15MB)이 게시판에 올라가는지, 안 되면 사내 공유 폴더 링크
  • SHA-256 해시를 본문에 적기받은 파일이 바뀌지 않았는지 동료가 확인할 수 있어요
  • 익명 점검세 글 같은 닉네임, 캡처·영상·파일 속성에 실명·사번·메일 주소 없음. 영상 속 Ttree 화면은 가상 인물(김가상)로 바꿔 그렸어요
  • 함께 출품한 두 글 링크 연결세 글이 서로를 소개해요

게시판 본문 텍스트 초안

이미지 위아래에 붙이는 글이에요. 이미지가 안 보여도 필수 항목 네 가지가 다 읽히게 했어요.

[어떤 업무에] 창 배치 전환, 회의록·보고서를 AI로 정리하기, 사내 용어 찾기, 결함 리포트 같은 양식 붙이기, 자리에 누가 왔을 때 화면 가리기, Ttree 출근·휴가 신청과 이석 챙기기처럼 하루에도 여러 번 반복하는 일에 써요. [무엇이 좋아졌는지] 회의가 끝날 때마다 창을 다시 늘어놓던 일은 단축키 한 번으로, AI에 붙여넣기 전에 고객사 이름을 손으로 지우던 일은 자동 가명 처리로, 사내 위키를 열어 약어를 찾던 일은 글을 고르고 Ctrl+Alt+W 한 번으로 바뀌었어요. 서류를 읽느라 마우스를 안 쓰고 있으면 이석 2분 전에 말랑 메이트가 알려 주고 마지막 30초는 초 단위로 세어 줘서, 자리에 있는데 이석으로 잡히는 일을 미리 막아요. [AI를 어떻게] 앱이 AI를 직접 부르지 않고, 우리 업무에 맞춘 프롬프트 9종에 선택한 글과 사내 용어 설명을 채워 클립보드에 넣어요. 보내기 전에 고객사·IP·경로를 다른 이름(CLIENT_A)으로 바꾸고, AI가 쓴 글은 ‘가명 되돌리기’로 원래 이름으로 돌려요. 회사가 허용한 AI라면 무엇이든 쓸 수 있어요. [사용법] 첨부한 Sure-Mate-Setup-0.1.0.exe를 실행하고(관리자 권한 필요 없음, ‘추가 정보 → 실행’), 첫 실행 안내 세 화면을 따라 하면 돼요. 팔레트는 Ctrl+Alt+Space, 용어 카드는 Ctrl+Alt+W, 화면 감추기는 Ctrl+Alt+H예요. 팔레트에 ‘출근’이나 ‘휴가 신청’을 치면 Ttree가, ‘메신저’를 치면 사내 메신저가 열려요. 트레이 메뉴의 ‘따라 해 보기’로 30초 연습도 할 수 있어요.
