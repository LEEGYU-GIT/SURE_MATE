말랑 메이트의 표정과 동작

부드러운 선으로 그린 말랑 메이트가 상황마다 보여 줄 모습이에요. 바꾸고 싶은 표정이나 빼고 싶은 동작이 있으면 알려 주세요.

가만히 있을 때숨 쉬듯 살짝 부풀고 가끔 눈을 깜빡여요.
통통 걷기작업 표시줄 위를 통통 튀며 다녀요. 내려앉을 때 납작해졌다가 다시 늘어나요.
바 옆면 기어오르기젤리라서 벽에 착 붙어 올라가요. 눈은 위를 봐요.
바 위에 앉아 쉬기꼭대기에 올라가 납작하게 퍼져서 눈을 반달로 감아요.
졸기한동안 아무 일이 없으면 퍼져서 잠들어요. 마우스를 가져가면 깨요.
집어 들었을 때마우스로 잡으면 반죽처럼 늘어나 대롱대롱 매달려요. 던지면 날아가 떨어져요.
프롬프트를 복사했을 때편지를 번쩍 들고 폴짝 뛰어요. 말풍선으로 붙여넣을 곳을 알려 줘요.
가명 처리가 켜져 있을 때선글라스를 쓰고 있어요. 지금 이름을 가리는 중이라는 표시예요.
가명 처리가 꺼진 채 복사할 때걱정스러운 얼굴로 주황 느낌표를 띄워요. 실명이 그대로 나간다는 경고예요.
